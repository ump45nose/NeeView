## 性能实测范围

每来源 96 次，同一进程、OS 文件缓存未清空；每次新会话和空像素缓存。首图终点是像素租约；不包含窗口上传/绘制。缓存需求不是翻页帧，几何查询不是滚动帧。固实归档为小图测试材料，不能与 4K 目录/ZIP 直接比较。

| 来源 | 首图 P95 | 已缓存请求 P95 | 万条目可见查询 P95 |
|---|---:|---:|---:|
| 目录，混合 4K JPEG | 376.40 ms | 0.005 ms | 0.001 ms |
| ZIP，同组 4K JPEG | 364.02 ms | 0.008 ms | 0.001 ms |
| 固实 RAR，小图夹具 | 12.06 ms | 0.007 ms | 0.001 ms |
| 固实 7z，小图夹具 | 13.18 ms | 0.003 ms | 0.001 ms |

原始样本在 directory/zip/solid-rar/solid-7z-benchmark.json。目录/ZIP 的 96 次工作集在约 250–600 MiB 间周期回收，末次约 280/286 MiB；并非查看器长期滚动数据。结束后的强制 GC 诊断单独记录，不将它作为正常浏览稳定或原生无泄漏的证明。

首版最终目标仍是：完整本地首图 P95 ≤1 秒、已预取分页 P95 ≤100 ms、缓存 60Hz 滚动 P95 ≤16.7 ms；后两项和绘制端首图尚未测量。
