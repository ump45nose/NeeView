## 真机与性能清单

- macOS 15+ ARM64，Retina、不同显示器、中文输入、精细滚动、捏合、Finder 打开、Command+W/Q、无窗口重开。
- 本地目录/ZIP 4K 首图 P95 ≤1s；预取分页 P95 ≤100ms；缓存 60Hz 滚动 P95 ≤16.7ms。
- 万条目只解码视口；连续切书后托管与原生内存均不线性增长。
- 固实 RAR / 7z、损坏条目、权限、NAS 断线、跨卷中断、覆盖恢复。
- Developer ID 签名、公证、干净系统安装。

本机初始环境：macOS ARM64，未安装完整 Xcode，`security find-identity -v -p codesigning` 返回 0。Windows 环境未提供。由本任务独立安装 .NET 10 SDK，不改变全局 SDK 配置。
