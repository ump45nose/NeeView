## 实施与构建

- 原 BookOperation、Book、Page、Archive、BitmapFactory 和 JSON 共用；唯一 ReaderView 内增加独立浏览表现辅助，不创建第二阅读内核、状态库或 Preview 入口。原分页规则保留。纵向逐图连续/最短列瀑布是 Mac 展示扩展，不视为原 PageFrameBox 全景算法等价迁入，见[契约](../docs/p3-browse.md)。
- 原窗口菜单、地址、左右侧栏及底部区域保持；地址行右侧选择分页/连续阅读/瀑布流。单击明确选择，双击图片进入分页；同书返回恢复浏览锚点。旋转、翻转等分页特有变换在浏览模式明确不可用，切回分页仍可用。
- 最终 [五步验证输出](p3-browse-validation.json)：Engine 构建、全量测试、正式入口 Library 编译检查、正式 ARM64 `.app` 构建、本地 ad-hoc 严格签名校验全部通过。默认 bin/obj 串行构建，未更换输出目录。
- 最终 **386/386 通过，0 失败、0 跳过**，包含显式启用的真实资源用例。新增回归覆盖万项混合尺寸查询、最短列/方向、配置失败回滚、双页设置下浏览位置、排序/窗口变化/缩放、模式切换取消旧拖动、鼠标选择/双击/修饰滚轮、晚到原生结果和关闭释放。
- 第一轮全量回归曾因旧 HistoryRetention 故障注入与阅读防抖保存并发而失败：未等待写入结束便在 `.tmp` 路径创建目录。保留 [失败输出](p3-browse-before-validation.json)；故障注入前等待 `SynchronizeWritesAsync`，专项及最终完整回归通过。这不是构建目录占用，也未通过更换输出规避。
- 原 235 个命令完整保留；当前 139 个执行入口、96 个占位。ToggleIsPanorama 只接入本批纵向浏览开关，原帧级全景范围仍标记待迁；入口数不是功能覆盖率，见[命令表](../docs/command-migration.md)。

## 用户资源只读速览

按用户澄清，从给定挂载资源根目录挑选三个直接包含图片的子目录，不要求递归浏览全部 387 个目录。测试使用临时 Profile，装载正式 XAML、ReaderView 和真实后端，未启动/激活正式 macOS 应用，未写入默认 Application Support 或资源目录。

每个样本检查顶部、30%、65%及底部四个滚动位置，然后切换连续、分页并返回瀑布。捕获实际 Headless 绘制结果，需求完成、至少两列及显示资源有界断言通过；末段仍可显示，不只验证首屏。末段锚点为可见项，未要求滚动到底时把最后一张强制设为主页面。
