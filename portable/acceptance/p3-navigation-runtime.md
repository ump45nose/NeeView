# P3 第二批：普通目录树及逐页缩略静默验收

日期：2026-10-04。基于 `10c988738` 实施。本批交付目录树/页面缩略可运行增量，**P3 未封板**；详细职责、出处、资源和未迁清单见[契约](../docs/p3-navigation.md)。

## 实施及验证

- 普通 FolderTree 迁入原父子/延迟/自然排序/选择/确认与祖先同步子集，通过既有来源枚举；Mac 实际 `/` 根替换 Windows 驱动器，不增加后端服务或 WPF 模拟层。树确认只改变书架，展开不切书。原 Top/Left、显隐、尺寸及同步开关写回 Bookshelf JSON。
- PageList 保留原 Normal/Content/Banner/Thumbnail，直接把当前 Book 的原 Page 交给同一 BitmapFactory；ZIP 缩略不用归档内部路径重新打开来源。方向键仅选择，普通按下/Enter确认，释放按 FocusMainView 及当前书籍身份回焦点；旧 Mac SelectionChanged 自动跳页退出。
- 万页测试覆盖可见/邻行容器有界、远端定位不逐项实现、离屏/模板/隐藏/关闭归还租约、旧 Page 原生晚到，以及真实 ZIP 来源身份。配置仍采用原 JSON，未迁 PageList 字段往返保留。
- 初次完整 402 项回归及 Engine/正式 Library/ARM64 应用/本地严格签名通过，见[初轮记录](p3-navigation-before-validation.json)。收尾增加祖先隐藏取消及禁选占位回归，修复拖动中书架回报重置 GridLength、快速释放等待导航和旧同步误清新错误。最终 **403/403 通过，0失败、0跳过**；Engine构建、正式视图测试、Library编译、正式ARM64.app及严格本地ad-hoc签名五步全部通过，见[最终验证](p3-navigation-validation.json)。初次验证不作为后续修复的通过证据。
- 所有构建串行、默认 bin/obj，无输出目录占用。途中新测试的 API 名称/几何类型编译错误修正后重新验证，未更换目录。前端结构、主题及资源所有权继续分离。

## 用户目录只读采样

按用户约定，从 `/Volumes/Picture/YY/秀人/5001-6000` 取三个直接含图的子目录，不递归或全量跑整个资源库。三个样本为59、81、78页，共218页。每书检查页面列表首段、中段及95%索引；跳到离屏项仅改变选择，正文保持，然后切换 Normal/Thumbnail、切书和普通树祖先链同步。

正式 XAML/共享列表/原 Page 和真实 Magick 后端在 Headless 运行，临时 Profile，不写资源目录或默认 Application Support，不启动/激活正式 macOS 应用，也没有真实键鼠操作。

| 样本 | 页数 | 三段实际显示缩略数 | 三段实现容器数 | 最大缩略计费（bytes） |
|---|---:|---|---|---:|
| 1 | 59 | 4 / 4 / 4 | 5 / 7 / 7 | 696,320 |
| 2 | 81 | 4 / 4 / 4 | 5 / 7 / 7 | 1,392,640 |
| 3 | 78 | 4 / 4 / 4 | 5 / 7 / 7 | 2,082,352 |

这些字节包含缩略像素/显示缓冲，跨书预算内缓存可以保留到回收；同一工厂关闭后租约及计费字节均为0。主图计费使用独立512 MiB目标，不把进程RSS等同于缩略计费。

每位置从实际完整帧的目标缩略区域读取5×5像素样本，拒绝纯色/空白；原图和像素值不输出、不入Git。仅证明该区域绘制了图片，不证明原图色彩准确性或设备像素1:1。已离线检查第二实图样本的中段缩略/选择及正文、合成PageList四模板和普通树自然顺序。

[匿名数值及截图指纹](p3-navigation-resource.json)保留9位置测量。真实截图只留本机忽略的 `portable/artifacts/p3-resource-thumbnails`；Git仅纳合成[页面缩略布局](p3-navigation-page-thumbnails-layout.png)及[目录树布局](p3-navigation-directory-tree-layout.png)，其他回归重复证据归档忽略目录，不覆盖P2/P3第一批。

SettleMs 包含150ms防抖、读取/解码等待和Headless捕获；冷离屏需求约数秒，不能把本次NAS抽样作为本地4K首图、预取翻页P95或屏幕60Hz验收。完整阶段性能和长期RSS/native仍待后续测量。
