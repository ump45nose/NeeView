# P5 阻塞与兼容收尾

## 职责、依赖及原出处

沿唯一Engine / Backends / MacOS、原Archive/BookOperation、JSON和FileOperationBackend事务继续适配。原VersionChecker仅检查版本并打开网页，没有自动安装器。原归档来源、命令及配置不改为第二业务体系；原Windows文件操作由Mac既有指纹/日志事务替换。

本批新增同一正式可执行文件的无窗口文件请求模式，隔离无法及时取消的挂载系统调用。没有新生产项目、常驻服务、外部CLI、语言、依赖库或框架分支。MacApp唯一装配FileOperationWorkerBackend；视图和Engine继续调用原接口。

## 文件操作契约、状态及资源

- 父进程以ProcessStartInfo.ArgumentList启动当前exe；路径/配置只在stdin JSON中传递，不使用Shell。请求及响应各限256KiB，stderr持续排空，不回显任意输出。协议使用System.Text.Json生成的类型信息，Release裁剪不依赖反射发现。
- 进程级单槽逐请求执行，worker复用原FileOperationBackend及同一FileRecovery日志。原FileTransferResult、改名/整书快照、覆盖副本、提交点和指纹规则保持。
- 已完成读取/写入/哈希及实际阶段转换报告进展，每200ms最多一条。默认连续15秒无真实进展启动取消，不发送虚假周期心跳。正常长文件不会因总耗时超过15秒被拒绝。
- 关闭/退出中断当前代次，包括排队请求。已开始请求先发送cancel，给原回滚约3秒；仍无结果则终止本次自己创建的worker。结果未知明确报告“结果未确认，恢复记录已保留”，不报告成功或已回滚，不改变未成功的移动历史。
- 真实成功结果优先于晚取消。提交成功后响应丢失时，Completed日志留待下一次原恢复协议核验；只按既有指纹清理，不猜测落点。覆盖、undo/redo和JSON路径联动继续沿同一链。
- OS未确认子进程退出时，资源及串行槽由后台排空任务持有；应用不无限等待，新请求有界报告队列暂不可用，不能与旧原生调用并发写入。
- 无UI入口在Avalonia/Trace/AppKit窗口初始化前分派，并清除macOS预设主线程同步上下文；不将异步继续执行派回被同步等待的主线程。输入流独立于Console.In的同步包装，取消监听不阻塞事务开始。
- CompressedArchive先逻辑关闭，拒绝新请求；实际释放仍等待读取gate。默认最多等待3秒，超时后来源持有自己的排空任务，原归档/缓存/嵌套父链只在实际读取结束后释放。迟到失败有诊断，重复关闭允许重试清理。

边界：只读SourceIo仍不能中断OS原生open/read，未返回的工作继续持有两个后台槽。逻辑关闭不会把它们标成已释放，也不代表挂载自动恢复。废纸篓/ZIP改写等其他系统写入口不在本批文件请求隔离范围，仍按各自契约等待真实结果。真实NAS断线后的正常退出/重连/完整性尚需独立复验。

## 分卷来源契约

- 普通目录中的RAR partNN、旧RAR .rar/.r00、7z/ZIP二进制.001序列、传统ZIP .zip/.z01使用同一SharpCompress有序卷集。任意卷打开定位到主卷，索引和固实抽取共用卷序列。
- 卷名/编号宽度精确匹配，检查首卷、连续卷号、重复编号及1024卷预算；不统一转小写猜测文件系统等价。ZIP EOCD/ZIP64卷号核验找到的物理卷数；RAR2没有首卷标志，依据合法.rar主卷及完整条目判断。
- 书架只在同次已有枚举中确认主卷存在时隐藏后续卷，不新增目录扫描；独立使用partNN名字的普通RAR保留。普通数字后缀如photo.001不变为归档候选。
- 所有卷流归SharpCompress来源拥有；读取输出仍为请求级独立流。多卷ZIP保持只读，不能进入单文件永久删除链。
- 口令请求及缓存使用规范主卷逻辑地址；只在整个打开验证成功后缓存。加密二进制7z分卷通过实际内容比对。
- SharpCompress 0.50.3明确不支持跨RAR卷解密。加密RAR分卷返回明确能力提示；加密目录可能需一次密码读取头部，但不循环询问、不缓存失败候选。嵌套分卷不借用随机单文件代理冒充完整卷集，明确要求先放入普通目录。

## Mac发布检查契约

IApplicationReleaseService由MacApp注入；版本窗口布局和阅读模型独立。用户明确点击检查时请求当前fork的公开latest release，限10秒/1MiB，不用token、不下载替换应用、不自动启动后台升级。原System.IsNetworkEnabled=false时不发起检查。

仅接受稳定版本、对应fork/tag页面和唯一Mac ARM64资产；Windows包、歧义命名、重复资产及外部地址不提示可安装更新。404明确表示没有发布。新版本的发布页/资产只在用户点击时交给既有系统链接接口，关闭取消并拒绝晚到结果。当前fork无正式Mac发行版不计为缺失安装器。

## 错误、测试和扩展

专项覆盖真实分卷/固实/RAR2/RAR5及二进制分卷的逐条SHA256、缺中/尾卷、ZIP首卷缺失、中文名、独立part名、书架去重、密码主卷定位、嵌套/加密能力边界和延迟资源释放。上游夹具固定0.50.3，来源、许可及SHA256在Fixtures/Multipart/sources.json。

原生后台覆盖真实同exe移动/覆盖撤销/目录复制/改名/三态恢复，忽略取消、排队取消、进展延长、晚取消成功、异常协议，以及真实提交后丢失响应再恢复。Engine验证关闭先中断文件请求再等待原导航锁；HTTP/窗口测试覆盖错误/超限/关闭、平台链接及原网络开关。

完整构建、自动/原生测试与开发包见[独立记录](../acceptance/p5-compatibility-runtime.md)。它们不替代真实SMB、设备/Windows、AX长期资源或正式分发验收。用户已授权并执行AX最小补丁隔离验证：静态返回引用增长消除，动态控件仍保留，触发节点生命周期改造停止条件，未接入产品；见[验证记录](../acceptance/ax-minimal-patch-evaluation.md)。不增加长期维护分支或禁用无障碍。未来官方依赖修复仍需动态释放及正式应用长期验收，不改变阅读/JSON/文件事务。
