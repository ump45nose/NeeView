# P2 第八批：原播放列表与全局页标记

本批迁入原PlaylistSource/PlaylistSourceItem、Playlist集合编辑、PlaylistHub选中文件与BookPlaylist/BookPageMarker关系。保持全局`.nvpls`，不建立Book私有标记、第二套阅读控制或数据库。

## 职责、依赖与契约

Engine持有原源格式、集合与原书内标记算法，SaveData装配全局PlaylistHub。BookOperation沿既有加载/定位入口打开普通图片或归档内逻辑路径。Mac独立PlaylistView管理列表/组合框/菜单/焦点，主题与结构可分开调整；不枚举目录或写文件。标记回报仅更新标记/菜单与面板，不重新解码正文。

## 本批业务范围

- `.nvpls`的Format/Items及Path/Name/Invalid、旧NeeViewPlaylist.1转换，未知字段保留；加载不自动覆盖旧源。新保存使用NeeView.Playlist/2.0.1。
- 默认Playlists/Default.nvpls与Pagemark.nvpls路径；枚举只固定Default首项，不添加尚未创建的Pagemark；原PlaylistFolder/CurrentPlaylist短路径/空值规则，Mac路径比较不统一忽略大小写。切换成功才更换当前集合，失败保持旧集合。
- 按Path去重，重复添加返回原对象；名称空或等于文件名省略。原延迟一秒dirty保存改为可等待的即时编辑提交，以便准确报告失败/回滚；插入、移除批次及逆序删除恢复、单项重排和原自然排序。编辑与原子写入串行，失败原地回滚，提交前检测到外部变更则拒绝覆盖。校验与替换之间不提供跨进程互斥保证；完整监视/外部协调待后续。
- 标记及原面板AddCurrentPage取已生效页面集合首项；未确认胶片/滑条选择不改目标。反向双页按原SelectedRange升序确定主图片；标记只处理当前主图，普通目录及已支持无密码归档可标记；双页/半页不扩成整屏多目标。书内按当前排序索引寻找前后标记，IsLoop/IsIncludeTerminal保持原默认false与算法。
- 前后播放列表文件循环；前后列表项按当前显示顺序，首尾不循环。普通目录/归档内路径进入同一原读取链，失效目标保持旧书并报错。
- 原面板上部组合框/更多菜单/过滤提示、下部列表；当前书过滤、分组、增删/更名/重排/恢复可用。未迁四显示模板、文件删除/更名、无效清理、OpenAsBook与链接修复保留禁用占位。
- 胶片条/页滑条标记可见开关使用原字段，标记绘制只消费页索引，不参与定位或解码。

## 状态与资源生命周期

播放列表由SaveData共享，条目身份在编辑/回滚中保留；删除恢复仅进程内且随切换列表重置。正文Book拥有当前页标记集合，切书/排序更新映射；跨书定位复用原代次和锁。配置仍在三JSON，列表文件独立原子保存；选择文件后保存Config，不宣称跨文件全局事务。新建先完整写入临时文件再以不覆盖模式提交，提交前支持取消，提交成功后完成当前源装配，不把已创建文件误报为取消。关闭必须等候列表编辑完成再保存阅读状态。

## 错误、测试和后续范围

损坏/未知新版本/权限/外部修改/取消必须保留原文件和可用集合，未完成打开不作用新书。专项需覆盖原格式/未知字段/去重/逆序恢复/保存失败、中文与归档内路径、单双/分割标记目标、前后边界/循环/首尾参数、排序重映射、正式XAML菜单与输入作用域、退出/重启与用户数据还原。

完整文件监视/路径修复、临时/媒体播放列表、Archive Playlist书籍来源、高级列表模板和完整旧路径迁移后续接入。每批源码manifest标记子集及出处，不用同名类型或命令数量声称完整迁入。Windows动态、真人设备/NAS、长期内存与完整P95仍独立待验。
