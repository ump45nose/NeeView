# P2 开发收尾清单

用户要求持续分阶段开发直至P2完成，未停止时不在每批提交后等待“继续”。本清单按当前代码核查记录待办，不能把未迁能力重分类为已完成，也不以测试数量代替功能覆盖。

P2范围保持原方案：漫画阅读、RAR/7z、历史/书签、胶片条、常用导航、输入配置/触控板及原窗口/侧栏交互。P3连续阅读/瀑布流/万图优化，P4分类文件操作，P5完整旧数据导入/高级媒体/嵌套/正式发布仍独立。
