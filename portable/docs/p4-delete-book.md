# P4 第八批：原整书删除与书架邻项

固定 `c5c398d89` 的 `DeleteBookCommand`、`BookControl.DeleteBook`、`ConfirmFileIO.DeleteAsync` 和 `NextFolderListBookLoader/GetNextItem` 是行为依据。沿用原 Book/BookOperation、书架集合及 JSON，不增加文件身份模型、数据库或第二内核。

## 职责、依赖与契约

- `BookOperation.CanDeleteBook/DeleteBookAsync`：删除当前书籍的真实根目录或根文件；不是当前图片。打开单张图片形成目录书籍时，删除对象仍是整个目录。
- `ConfirmDeleteBookAsync(path)`：宿主呈现独立的整书确认，明确目录包含全部文件；只返回选择，不执行文件动作。原 `System.IsRemoveConfirmed` 控制确认，无宿主且需要确认时拒绝提交。
- `IPlatformService.TrashAsync`：复用唯一系统替换点。正式 Mac 通过 `NSFileManager.TrashItem` 移入废纸篓，支持真实文件和目录；失败传播系统错误，不永久删除回退。
- `BookshelfFolderList.GetNextItem(path, selectedItemFallback)`：保留原下一项优先、末项退前、单项为空；不在列表时可回退当前选中项。
- `IArchiveFactory.GetPhysicalPathAsync`：只在实体操作时解析系统路径，不改变Book/JSON定位；Mac后端在既有有界I/O中调用系统realpath，保留文件系统实际大小写和系统链接语义。缺失的Profile末段从最近实际祖先拼接，权限/其他错误明确失败，无可靠后端时不允许删除。
- 原 `Bookshelf.IsOpenNextBookWhenRemove=true` 进入现有配置/设置事务。关闭开关仍刷新书架，只停止自动打开邻项。

## 状态与资源生命周期

与 DeleteFile 共用删除忙碌锁，阻止重复删除、重命名、复制和分类重入。确认前捕获书籍与代次，不持导航锁；确认后重新获取锁，复核同一本书、写权限及真实元数据。准备/确认阶段关闭可取消，已授权系统工作由关闭流程等待真实结果。

系统动作前保存旧 memento，取消旧保存/打开需求，失效页面与封面缓存并释放原来源，再清空当前书籍/页框。删除失败或提交前取消时，通过唯一原打开链恢复旧 memento、条目、搜索及锁定；不复用已释放 Archive。系统成功后清除已删除的 LastBook 启动目标，历史和书签保留，删除不进入分类移动撤销栈。JSON 保存失败报告实体已删除，保留待清除标记，通过防抖/手动保存/退出重试。

书架位置未改变时刷新当前列表，再按删除前捕获的邻项打开。新打开请求按原代次优先，晚到删除结果不覆盖新书、错误或主动书架导航。仅有一项或没有可用邻项时保持空查看器。

## 范围、业务差异与错误

临时列表、归档内部逻辑目录、卷根、Profile 目录及其祖先拒绝整书删除。用户真实 `.nvpls` 只删除列表文件，不删除引用图片。确认前后缺失、类型/元数据变化或链接替换拒绝提交；另用实际路径检查Profile祖先、临时根及卷根，防止大小写别名或系统/var链接绕过文字保护；正式后端另拒绝目标及父路径链接，保留系统 `/var → /private/var` 特例。目录内已有链接随目录整体移走，不遍历或删除链接所指外部实体。

原 `BookControl.DeleteBook` 未检查 `ConfirmFileIO.DeleteAsync` 的 false 返回，取消/失败仍可能继续下一书。本批明确修正：**只有真实成功才自动导航**；取消保持旧书，系统失败恢复旧书。该项属于记录在案的必要改造，不宣称逐字等价。

不存在、权限不足、系统废纸篓不可用、确认期间变化、状态保存/重开/书架刷新失败分别报告。真实删除后失败提示不得冒充文件回滚。临时路径检测与来源根资格不扩大到列表引用或压缩包内部条目。元数据复核不能宣称提供跨进程原子身份保证。

## 前端与扩展点

主菜单保留原 DeleteBook 名称、顺序和禁用资格；只通过既有可等待文件任务转交 Engine。确认窗口复用独立布局/主题，设置页只编辑原字段草稿。文件目标、邻项算法、缓存失效、JSON 与关闭等待不进入 XAML 或控件，样式可独立调整。

普通书籍页、页面列表多选、归档内不可逆删除与链接删除继续单独迁移；本批不等同完整 DeleteFile，也不替代其他书籍移动/复制菜单。

## 测试与设备验收

临时真实目录、归档和用户列表配合模拟废纸篓，覆盖整书范围/引用保留、历史/书签、前后邻项及开关、选择回退、无授权、失败恢复页面/搜索/锁定、确认期间切书/关闭/撤权、临时/Profile/归档内部保护、实体变化、Profile/临时根路径别名、未创建Profile末段、目录内部链接外部目标保留、关闭等待、晚取消、新打开优先与 JSON 失败重试。正式 Headless 覆盖菜单、独立确认及设置原字段保存，并输出合成整书确认截图。

模拟废纸篓不是 AppKit 真机结果。正式 Library/ARM64 `.app` 构建和严格本地 ad-hoc 签名分别留证；真实废纸篓、权限/跨卷/NAS、Mac 焦点/弹出层、Windows 动态、无损 Retina 和长期原生内存随 P3/P4 集中验收。常规验证不启动/激活正式应用，不改系统剪贴板或用户图片资源；触控板跳过，多屏无环境。
