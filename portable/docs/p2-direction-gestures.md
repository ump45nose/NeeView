# P2 第二十三批：原方向手势

## 职责与依赖

原 MouseSequence、方向转换器、MouseSequenceBuilder 与进度事件迁入 Engine；只替换 WPF 坐标与夹角计算，保留距离门槛、方向夹角、更新起点、C 终端与序列相等规则。Mac ReaderView 管理捕获和提示，MainWindow 查原命令表并进入唯一命令入口。主题/布局与阅读规则独立，无轨迹绘制或第二输入登记表。

## 契约与状态

固定清单235个命令补齐原12个非空默认 MouseGesture。原 A/B/C 不改变方向序列；默认阅读方向交换配对绑定，运行时沿原输入反转。`Commands.<Name>.MouseGesture` 独立于 ShortCutKey，空字符串解绑，默认差分省略。Mouse.IsGestureEnabled 默认true、GestureMinimumDistance默认30 DIP，Windows系统最小拖动值替换为5 DIP下限，未知字段合并保留。

无修饰独占右键开始，按原阈值及夹角追加方向；释放确认，已有序列时左键追加C后确认。未知方向也消费本次操作，不退化为右击。普通空右击仍按键位执行；命中的组合轮滚取消序列并抑制释放。Escape、捕获丢失、失焦、切书、关闭及作用域失效取消；加载/对话框/菜单不启动序列。提示保留命令文本及方向箭头，不绘制轨迹。

原方向字典后登记覆盖已有重复；设置草稿新增冲突显示命令名称，已有冲突不阻止无关设置保存。未迁命令配置保留，执行进入统一能力提示。设置窗口独立方向列、开关和距离，取消不写；保存失败同时恢复Mouse分支及原Commands节点。

## 错误与验证

非法新输入及新增冲突保存前拒绝；旧序列继续原解析容错。专项覆盖原距离/夹角/斜线、C终端、默认配对、差分/解绑/重启、未知参数、释放/取消/轮滚和保存失败重试。全量和正式构建见独立记录；不启动正式应用，不读取用户数据。实际鼠标捕获/IME与Windows动态对照待集中真机验收。

## 扩展点

Hover/MouseWheelScroll 属于原独立鼠标分支，下一动画批接入；高级拖动动作和触摸屏手势保持能力清单，不以本批测试冒充完整输入覆盖。
