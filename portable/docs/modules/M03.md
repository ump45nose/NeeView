# M03：图像解码与像素资源

## 职责

图像解码与像素资源；以下描述当前实现和后续验收边界，不把设计目标当作已验收结果。

## 依赖

Imaging → Application；Magick.NET Q8。Desktop 负责像素到 Bitmap 的适配。

## 契约

`ProbeAsync(Stream, token)` 返回显示方向后的尺寸与格式。`DecodeAsync(Stream, DecodeRequest, token)` 返回 `DecodedImageLease`。
租约提供 Size、Stride、ByteCount、BGRA8 预乘像素及 Dispose；Core 不出现 Avalonia Bitmap。

## 状态与资源生命周期

每次调用独占流和 MagickImage；using 释放原生对象。像素租约归还前可读，归还后禁止访问。原生调用结束后再检查取消。

## 业务规则

- JPEG、PNG、WebP、BMP、TIFF；GIF 仅首帧。AutoOrient 处理 EXIF，ICC 转换到 sRGB。
- 输出 8 位 BGRA，alpha 预乘；用户旋转和分割由布局/查看器处理。
- 估算解码工作预算 256 MiB；JPEG 使用采样 hint，最大八倍；不能安全采样的格式拒绝超限。
- 目标大于原图不会放大；图像错误保留原条目供继续导航。

## 错误

损坏文件、非可定位流、超预算和取消返回明确结果；不在 UI 线程执行解码。

## 测试

NativeAndSchedulerTests、ProgressiveTests、CoreTests；EXIF、GIF 首帧、透明预乘、JPEG 不放大、错误与取消。ICC 多样样本及原生长期泄漏仍需真机验收。

## 扩展点

其他解码实现必须满足同一像素和所有权契约；动图帧序列后续单独扩展。
