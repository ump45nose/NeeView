# M01：内容模型与阅读规则

## 职责

内容模型与阅读规则，实现范围按整体架构和阶段验收表约束。

## 依赖

Core；不引用 UI 或存储。

## 契约

SourceLocator、BookId、ContentId、PageDescriptor、ContentVersion、ReadingAnchor、ReaderOptions；ReadingRules 和 ILayoutStrategy。接口变更同步调用方和本文件。

## 状态与资源生命周期

身份持久化；描述和布局不可变；相对锚点在重排后恢复。

## 业务规则

仅单页分割宽图；双页宽图独占；首尾单页；按字段恢复默认/当前/历史设置；自然排序保持身份。

## 错误

空集合返回空布局；非法输入限制范围。

## 测试

左右、单双、分割、负半页位置、奇数、宽页、排序。自动测试与真机验收分别记录。

## 扩展点

新增布局、排序与规则采用纯函数。
