# M01：书籍、页面与阅读控制

## 职责

保留原位置、范围、排序、按字段设置恢复与页框判断顺序。P2已接入目录/ZIP/RAR/7z分页、真实书籍页/父子书、全局标记/导航历史、锁定/页尾与变换控制；P3已接入原帧全景、Mac连续/瀑布、渐进索引和原页面搜索；高级媒体/metadata/rating仍在P5。

## 依赖与契约

Engine 仅依赖 .NET 与原 MVVM 辅助库。Book 拥有 Archive 和 Page 列表，Page 关联 ArchiveEntry；BookOperation 提供 OpenAsync、MoveAsync、JumpAsync、ApplySettingAsync、SetViewport、SaveAsync、DisposeAsync；第三批增加PageSelector、MoveSizeAsync、NavigateHistoryAsync及GetPageInformationAsync，第四批增加Bookshelf、MoveBookAsync及MoveFolderPageAsync。PagePosition/PageRange 与原枚举保持兼容，Changed 只通知状态，订阅方切UI线程。

## 状态与资源生命周期

打开代次防止晚到书籍提交；导航/设置/提交使用互斥。旧书先保存，新来源成功才替换。Book关闭释放来源；显示像素独立由BitmapFactory持有。保存失败不将操作永久标记为关闭。

## 业务规则

完整迁入 PageFrameFactory；双页、封面/末页单页、宽图与分割保留原判断。NextPage按帧/半页，NextOnePage在双页按原单页步进。普通书籍的Entry排序按原BookSourceFactory回退文件名；重排保持当前Page对象。恢复使用原Mix按字段选历史/默认/当前，Page为条目名；终页重置按原条件。普通非递归目录有界渐进提交；递归展平和归档仍完整索引，未完成的收集末项不是实际页尾。临时选择与正文分离；指定步长沿用原周期归一/静态对齐、CorrectPosition端点终止。页面历史保存最小显示条目，成功重放才提交游标，失败保留当前书。

## 错误

空目录是有效空书；损坏图保留占位。打开失败保留旧书，取消或过期结果只释放来源。非支持格式返回能力提示。

## 测试与验收

OriginalPagePositions迁入原测试；ReadingTests覆盖左右/单双/奇数/宽页/分割、策略、Props及真实目录/ZIP恢复。第三批SelectionHistoryTests覆盖两种历史、分支、失败重试、并发取代、指定步长与终点半页；Windows动态阅读样本对照待验证。

## 扩展点

原BookPageCollection目录组算法仅文件名升/降序有效，组内后退先回本组首项；普通前后书按书架选择和原排序取邻项，成功才更新选择，默认加载中忽略切书，原优先模式允许取代。ResetNextBookPageMode未混用于普通切书。BookshelfNavigationTests覆盖端点、恢复、失败重试、加载取代和两种排序方向；真实Folder页/父书定位已由第十五批接通。契约见 ../p2-bookshelf-navigation.md。P3连续/瀑布流以原Page及位置体系扩展，不另起阅读内核。出处见source-migration.json。

第十五批增加BookAddress/Entries与原PageType，MoveToParentBookAsync/MoveToChildBookAsync/OpenChildBookAsync/ToggleRecursiveFolderAsync共用唯一加载链；真实条目及所属书籍核对，失败保留旧书。位置变化在原互斥/代次中裁决，详情见../p2-book-hierarchy.md。

第十八批原BookHub锁定、BookPageTerminator页尾、PageFrameFactory无缝循环及可复用Unload接入；普通切书不强制套用页尾重置，详见../p2-book-controls.md。

P2收尾保留正反向单双页切换及原共享IsLoop参数：默认循环，关闭循环时在首末模式停止；进入同一ApplySettingAsync/页框/JSON链。

P3收尾契约：SourcePages保留全部原Page，当前Pages经原搜索/排序重新编号；SourceVersion只表示来源变更，PageOrderVersion表示正文顺序。空结果无帧但保留原阅读条目；标记映射来源页，正文导航排除被过滤页。目录代表页及Smart公共前缀从全源建立。后台布局、原帧全景/PagesAsOne、指针缩放和搜索中渐进补齐均有专项回归，见../p3-completion-checklist.md和../p3-page-search.md。

P5第十八批：原幻灯播放/首周期等待/页尾覆盖/自动滚动、顶部计时条与独立设置草稿接入；唯一阅读/JSON链保持，关闭失败恢复播放及滚动，见[契约](../p5-slideshow.md)。

P5第二十一批：原随机跳页/来源资格排序、地址栏/滑条菜单与快捷键语义、窗口状态与独立设置目录进入唯一命令链。正文与Chrome通知分离；关闭取消/等待系统目录动作。见[契约](../p5-original-commands.md)。
