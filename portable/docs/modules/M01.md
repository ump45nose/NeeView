# M01：书籍、页面与阅读控制

## 职责

保留原位置、范围、排序、按字段设置恢复与页框判断顺序。P1实现目录/ZIP分页；媒体、搜索、标记和高级控制未完整迁入。

## 依赖与契约

Engine 仅依赖 .NET 与原 MVVM 辅助库。Book 拥有 Archive 和 Page 列表，Page 关联 ArchiveEntry；BookOperation 提供 OpenAsync、MoveAsync、JumpAsync、ApplySettingAsync、SetViewport、SaveAsync、DisposeAsync；第三批增加PageSelector、MoveSizeAsync、NavigateHistoryAsync及GetPageInformationAsync，第四批增加Bookshelf、MoveBookAsync及MoveFolderPageAsync。PagePosition/PageRange 与原枚举保持兼容，Changed 只通知状态，订阅方切UI线程。

## 状态与资源生命周期

打开代次防止晚到书籍提交；导航/设置/提交使用互斥。旧书先保存，新来源成功才替换。Book关闭释放来源；显示像素独立由BitmapFactory持有。保存失败不将操作永久标记为关闭。

## 业务规则

完整迁入 PageFrameFactory；双页、封面/末页单页、宽图与分割保留原判断。NextPage按帧/半页，NextOnePage在双页按原单页步进。普通书籍的Entry排序按原BookSourceFactory回退文件名；重排保持当前Page对象。恢复使用原Mix按字段选历史/默认/当前，Page为条目名；终页重置按原条件。P1目录索引完整后显示，未实现渐进索引。临时选择与正文分离；指定步长沿用原周期归一/静态对齐、CorrectPosition端点终止。页面历史保存最小显示条目，成功重放才提交游标，失败保留当前书。

## 错误

空目录是有效空书；损坏图保留占位。打开失败保留旧书，取消或过期结果只释放来源。非支持格式返回能力提示。

## 测试与验收

OriginalPagePositions迁入原测试；ReadingTests覆盖左右/单双/奇数/宽页/分割、策略、Props及真实目录/ZIP恢复。第三批SelectionHistoryTests覆盖两种历史、分支、失败重试、并发取代、指定步长与终点半页；Windows动态阅读样本对照待验证。

## 扩展点

第四批保留原BookPageCollection目录组算法，仅文件名升/降序有效，组内后退先回本组首项；普通前后书按书架选择和原排序取邻项，成功才更新选择，默认加载中忽略切书，原优先模式允许取代。ResetNextBookPageMode未混用于普通切书。BookshelfNavigationTests覆盖端点、恢复、失败重试、加载取代和两种排序方向；真实Folder页/父书定位仍待迁。契约见 ../p2-bookshelf-navigation.md。P3连续/瀑布流以原Page及位置体系扩展，不另起阅读内核。出处见source-migration.json。

第十五批增加BookAddress/Entries与原PageType，MoveToParentBookAsync/MoveToChildBookAsync/OpenChildBookAsync/ToggleRecursiveFolderAsync共用唯一加载链；真实条目及所属书籍核对，失败保留旧书。位置变化在原互斥/代次中裁决，详情见../p2-book-hierarchy.md。
