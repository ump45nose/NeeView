# M01：内容模型与阅读规则

## 职责

内容模型与阅读规则；以下描述当前实现和后续验收边界，不把设计目标当作已验收结果。

## 依赖

Core，仅依赖 .NET；不引用 WPF、Avalonia、SQLite 或解码库。

## 契约

`SourceLocator(Path, Entry)` 区分文件与归档逻辑定位。`BookId`、`ContentId` 与临时文件名分离；`ContentVersion(Length, ModifiedTicks)` 用于缓存失效。
`ReadingAnchor(Content, Part, RelativeY)` 表示资源、半页与页内比例。`ReaderOptions` 是不可变配置；`OptionRestore.Mix` 逐字段选择 Default、Continue、RestoreOrDefault、RestoreOrContinue。
`ReadingRules.Frame/Navigate` 输出分页组合及下一锚点；`PageOrdering.Sort` 只改变序列，不改变身份。

## 状态与资源生命周期

模型和布局快照是纯值；数据库负责跨进程身份登记。应用内移动调用 Relocate 保持身份；外部移动不按摘要猜测身份。

## 业务规则

- 仅单页模式分割宽图；双页模式宽图独占，封面/末页单页参与前后 frame 规则。
- NextPage 按 frame/半页前进，NextOnePage 按原图片前进；边界不循环。
- 自然数字排序使用确定的比较器；随机排序以身份和种子稳定计算。
- 历史锚点可能晚于目录首批；完整索引结束前不能判定它已失效。
- 差分恢复策略中缺失的字段使用 RestoreOrDefault，有历史时恢复每本书设置；仅显式 Default 使用默认值，不能将字典缺失误判为枚举零值。

## 错误

空集合输出空 frame；无效页内比例限制到 0–1。未知外部路径需用户重新定位。
