# M07：界面、导航与输入

## 职责

界面、导航与输入；以下描述当前实现和后续验收边界，不把设计目标当作已验收结果。

## 依赖

Desktop → Application → Core；不引用 Content、Persistence、Imaging 或 Platform.MacOS 项目。

## 契约

主窗口只组合 ReaderView、ReaderNavigationPanel、ReaderDestinationPanel 与 SettingsWindow。
ReaderWorkspaceViewModel 和 Panels partial 管表现状态/业务协调；IReaderDialogs 是交互端口。ReaderInputRouter 管手势映射；ReaderLabels 管显示文本；ReaderTheme.axaml 管样式。
PanelsChanged 是可等待 Func<Task>，面板数据用 NavigationData/DestinationData，视图不负责路径枚举和书签写入策略。

## 状态与资源生命周期

控件拥有自己的选择/滚动与模板。窗口面板刷新串行，受取消令牌/代次保护；快照同步投递 Dispatcher，设置回调切 UI 线程。关闭停止订阅，晚到任务不更新控件。

## 业务规则

- 前九手动目录稳定数字命令；文本框和模态对话框隔离数字输入。
- 新默认系统键位用 Command；旧 Control 导入保留，冲突报告所有命令和参数。
- 导航含页面/缩略图、目录延迟展开、历史、书签树及信息；分类两区独立滚动。
- 设置页分别编辑当前书籍、默认阅读、恢复策略、键鼠和分类侧栏。
- 鼠标命令与高精度滚轮残余量、Pinch 起始缩放和原生 Magnify 增量分开处理；真实触控板差异需真机确认。

## 错误

控件异步事件通过统一观察器报告错误；不从全局窗口反查业务对象。快捷键未知项保留报告。

## 测试

Headless UiTests 覆盖文本数字隔离；模块测试覆盖键位归一/参数冲突。最新包因 Mac 锁屏未完成交互复测。

## 扩展点

详见 ../frontend-boundaries.md；调整模板/样式不改工作区、Core 或文件服务。
