# M07：界面与输入

## 职责

界面与输入，实现范围按整体架构和阶段验收表约束。

## 依赖

Desktop → Application。

## 契约

稳定命令标识；快捷键字符串/参数分开；输入作用域。接口变更同步调用方和本文件。

## 状态与资源生命周期

UI Dispatcher 更新；对话框/文本焦点隔离；侧栏比例设置保存。

## 业务规则

数字 1..9 分类；导入 Control 保留；Command 系统操作；滚轮/触控板区分；捏合围绕指针。

## 错误

冲突显示命令；未知命令报告。

## 测试

中文输入、焦点、键位导入、目录延迟、手势。自动测试与真机验收分别记录。

## 扩展点

平台手势桥接与可定制鼠标。
