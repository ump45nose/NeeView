# M04：窗口、面板与主题

## 职责

原 XAML 区域和资源为布局基准。用户已认可总体布局；本轮恢复完整菜单占位、历史/书签/导航器与胶片条，侧栏拖拽自动组合列为后续目标。

## 依赖与契约

MacOS 视图/表现只依赖 Engine。MainWindow.axaml 定义结构；资源/主题独立；ReaderWorkspaceViewModel 绑定原 Page/BookOperation。Refreshed 表示阅读刷新，PanelsRefreshed 仅表现更新。MenuPresenter 由完整 MenuNode 树、能力回调及勾选回调生成菜单，不筛除未迁移节点。

## 状态与资源生命周期

窗口拥有表现订阅、目录请求和滑条防抖。宽度/显隐/基础自动隐藏保存 JSON；GridSplitter 隐藏重显保持实际宽度。胶片条默认关闭；可见窗口和导航器单页使用独立显示租约，隐藏/关闭取消需求并释放。

## 业务规则

顶部八组原菜单和地址、中央图像、左右 41 DIP 栏/36 DIP 图标、底部胶片条/滑条/状态。默认左 Folder/PageList/History，右 Information/Navigate/Effect/Bookmark/Playlist/Destination。历史搜索/双击、原书签树基础编辑、导航器定位、胶片条按阅读方向选择接入；其余禁用占位。先还原结构，主题现代化另做增量。

## 错误

读取失败保留当前书；未迁移命令和面板显示阶段提示。书签失败原地恢复节点。主题缺失由 XAML 测试暴露。

## 测试与验收

正式 XAML/Skia 绘制，区域/栏宽/分隔拖动与显隐、完整八组菜单与禁用节点、历史/书签、可见缩略图与隐藏释放、非查看器手势隔离。P2 截图与正式运行记录分开保存；原 Windows 截图/动态对照仍未取得。

## 扩展点

P2 后续独立增量（进入 P3 前处理）：图标跨左右栏移动与重排、拖入现有组自动组合、边缘分割形成面板组、组间比例/顺序/选择恢复、拖动时自动隐藏锁定、未迁入面板可识别占位。依据原 LayoutDockPanel/SidePanelDropAcceptor 迁移，不引入大型停靠框架。当前七列固定结构不等于已支持停靠组合。原胶片条预览选择、防抖、详情与完整滚轮模式尚未迁完。
