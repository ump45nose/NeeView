# M04：窗口、面板与主题

## 职责

原 XAML 区域和资源为布局基准。用户已认可总体布局；完整菜单占位、历史/书签/导航器与胶片条、原侧栏拖拽组合/自动隐藏/浮动与布局恢复已接入，前端布局/主题/表现与业务分开。

## 依赖与契约

MacOS 视图/表现只依赖 Engine。MainWindow.axaml 定义结构和九个唯一内容；资源/主题独立；ReaderWorkspaceViewModel 绑定原 Page/BookOperation。Refreshed 表示阅读刷新，PanelsRefreshed 仅表现更新。SidePanelPresenter 排布原 LayoutPanelManager 数据，负责拖放/预览与分隔条，业务模型不包含控件。MenuPresenter 由完整 MenuNode 树、能力回调及勾选回调生成菜单，不筛除未迁移节点。

## 状态与资源生命周期

窗口拥有表现订阅和滑条拖动状态；普通书架请求及取消归BookOperation中的BookshelfFolderList，200ms缩略需求防抖由ThumbnailView拥有。宽度/显隐/基础自动隐藏保存 JSON；组方向/顺序/选择/比例使用原 Layout 节点。内容控件跨栏复用并显式绑定表现模型，拖动提交前不改变布局，取消/关闭释放捕获及自动隐藏锁。胶片条默认关闭；可见窗口和导航器单页使用独立显示租约，隐藏、脱离视觉树和关闭取消需求并释放。

## 业务规则

顶部八组原菜单和地址、中央图像、左右 41 DIP 栏/36 DIP 图标、底部胶片条/滑条/状态。默认左 Folder/PageList/History，右 Information/Navigate/Effect/Bookmark/Playlist/Destination，之后允许重排。leader 图标移动整组，其他成员可拆组，内容落点按原规则形成分割组。历史搜索/双击、原书签树基础编辑、导航器定位、胶片条按阅读方向选择接入；其余面板可选择占位，未迁移菜单禁用。先还原结构，主题现代化另做增量。

## 错误

读取失败保留当前书；未迁移命令和面板显示阶段提示。书签失败原地恢复节点。主题缺失由 XAML 测试暴露。

## 测试与验收

正式 XAML/Skia 绘制，区域/栏宽/分隔拖动与显隐、完整八组菜单与禁用节点、历史/书签、可见缩略图与隐藏释放、非查看器手势隔离。第二批覆盖原组移动/拆组/组合、唯一性、方向判断、JSON 未知字段及实际 Headless 拖放/取消；真机验证组合与比例恢复。P2 截图与正式运行记录分开保存；原 Windows 截图/动态对照仍未取得。

## 扩展点

继续按原 LayoutDockPanel/SidePanelDropAcceptor 扩展必要细节，不引入大型停靠框架。单面板浮动/关闭/重开/停靠、五区自动隐藏、胶片条临时选择/详情/三滚轮、滑条联动释放确认/直接页号/全局标记均已接入。FolderPanel保留原混合列表、独立浏览/同步/刷新、真实Folder页/可见封面/每目录参数；纯书架更新不请求正文，列表方向键/Enter单独处理。旧V0/V1布局导入、主视图浮动、高级树布局、完整目录树/大量图片和高级触摸细节仍待后续。契约见 ../p2-bookshelf-navigation.md、../p2-selection-navigation.md、../p2-autohide.md 和 ../p2-floating.md。

第五批书签树接通移入/边缘重排、Esc/树外取消、批次删除恢复；独立登记XAML保留名称/目标/动作，完整原Popup标签/树选择器待迁。

第十五批独立ArchivePageRenderer转换原480×640书籍卡片、上3/下1区域及Uniform封面；主题颜色独立。封面单击隔离/双击实际书籍、动态菜单能力与逐页错误接入，目录/ZIP真实卡片Headless有独立截图，详见../p2-book-hierarchy.md。

第十七批ReaderTransformPresenter分离原变换数值与显示矩阵，导航器/绘制/命中共用。CommandParameterWindow独立属性布局，父表单草稿/取消不改变业务，详见../p2-view-transform.md。
