# M02：内容来源与归档

## 职责

保留原 Archive/ArchiveEntry 所属关系、条目 ID 与来源定位，替换 Windows 读取后端。目录、单图所在目录、ZIP/CBZ 已有 P1 证据；P2 首批增加普通/固实 RAR、CBR 和 7z。

## 依赖与契约

Backends → Engine。IArchiveFactory.OpenAsync(path,token) 返回调用方拥有的 Archive；ListFoldersAsync 返回只读直接子目录，ListBooksAsync 返回直接目录及支持归档的元数据候选，不打开/解码各本书。GetEntriesAsync 建立索引，OpenEntryAsync 返回必须释放的可定位独立流，DisposeAsync 释放来源。

## 状态与资源生命周期

SourceIo 全局后台槽 2，队列/执行等待边界各 15 秒；不可中断调用仍占槽并清理晚到来源/流。归档互斥覆盖抽取及关闭。非固实小条目内存流，大条目随机临时文件 DeleteOnClose；固实及 7z 使用独立顺序 Reader，避免释放 Reader 破坏原索引来源。抽取结果用应用随机文件名，每来源 2 GiB LRU；关闭清理，返回的流在来源关闭后仍归调用方拥有。

## 业务规则

图片转所在目录并定位文件，隐藏点文件过滤。普通文件名保持文件系统大小写及合法反斜线。归档内部路径仅作逻辑定位；ID 区分索引重复条目，7z 顺序 Reader 按名称及同名序号寻找，不能以索引序号匹配物理序号。实际解压长度必须与索引相符。普通非递归目录按128项批次发布，已知图片可先产出；递归及归档仍完整索引后原过滤排序。UI不枚举或解压。分卷后缀和 RAR 分卷头明确拒绝，密码/分卷/嵌套不宣称支持。

## 错误

不存在、权限、超时、损坏、加密和不支持分别传播真实错误。取消只结束等待，晚到资源清理。NAS 按已挂载目录处理，断线真机未验。

## 测试与验收

中文目录/CBZ，加上 Rar.rar、Rar.solid.rar、Rar5.solid.rar、7Zip.LZMA.7z、7Zip.solid.7z 的乱序重复读取/真实解码、取消、关闭后独立流继续读。保留夹具版权和 SharpCompress 许可。重复同名 7z 身份、加密/分卷边界、损坏固实包及 NAS 仍待专门夹具或真机。

## 扩展点

书架枚举进入同一SourceIo有界后台任务，坏包保留候选，真正打开时返回错误；BookshelfFolderList拒绝取消/过期结果，失败保持旧位置和列表。真实目录/归档候选、取消/关闭/失败重试有专项测试；每目录参数和书籍递归已接入，普通目录递归搜索、Mac/挂载卷根、QuickAccess和按需监视已由P3接入；高级来源能力仍按清单迁移。继续原 Archive 抽象扩展密码/分卷/嵌套，不增加身份层。跨来源总缓存预算、崩溃遗留临时缓存回收尚未实现，不能把每来源 2 GiB 宣称为进程总限额。

第十五批ArchiveEntryCollection拥有根和递归子来源，反向释放；CurrentDirectory补隐式ZIP目录，ArchiveDirectory保留物理ID快照，逻辑目录书架共用原来源集合。shortcut防环，坏子书保留，真正嵌套压缩明确P5，详见../p2-book-hierarchy.md。

P3增加既有来源契约ListSearchBooksAsync/WatchBookSearch：目录搜索后台枚举真实元数据，不进入符号链接目录；活动搜索根最多一个，普通展开节点一级监视最多32项，250ms合并。隐藏/关闭释放及旧ID隔离；归档逻辑位置不启动文件监视。取消、错误及非递归渐进追加保留已提交页/列表，见../p3-index.md、../p3-quickaccess.md、../p3-page-search.md。
