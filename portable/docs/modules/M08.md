# M08：macOS 生命周期与高级能力

## 职责

唯一正式Host装配、Finder/菜单/拖放打开、窗口关闭与应用退出；高级格式及发布属于后续目标。

## 依赖与契约

MacApp装配Engine/Backends/MacOS表现，只有这里创建具体后端。MacOS/Backends使用net10.0-macos、官方Foundation/AppKit。Program是唯一Exe入口；MainWindow.OpenAsync/RestoreLastAsync/PrepareShutdownAsync可等待。

## 状态与资源生命周期

窗口初始化共用Task，激活等待初始化完成，单窗口。Command+W完成保存后关窗口，应用驻留；Dock重开装配新窗口并恢复最后书籍。Command+Q等共享关闭准备后退出；失败保留窗口并可重试。Finder打开/拖放进入同一个BookOperation加载流程。

## 业务规则

macOS15+、Apple Silicon；完整Xcode必须匹配macOS workload，不新建Preview绕过。保留Info.plist版本/核心格式声明，RAR/CBR/7z已接入并向Finder声明；密码/分卷/嵌套不宣称支持。发布ARM64自包含.app；脚本只处理正式Host，实际ARM64解析资产/原生文件/许可与基线提交随包记录，见[分发契约](../p5-distribution.md)。

## 错误

本机已安装匹配workload的Xcode27.0。SDK修改原生库加载路径后需要完整签名，开发工程明确采用ad-hoc及JIT权限；最终默认输出目录.app通过codesign严格校验，RID子目录.app是签名前中间产物。Library源码检查不等于可运行.app。启动损坏JSON保持原文件；系统API失败传播，不以永久删除替代废纸篓。

## 测试与验收

正式构建/本地签名、Headless布局/输入/关闭任务通过。P2 原生输入桥接在窗口建立后装配，关闭后释放 AppKit 本地 monitor，不向设置/其他窗口消费手势。真机已验证目录/CBZ、系统打开事件、Command+W后进程驻留及系统重开恢复、Command+Q退出、完整重启恢复、冷启动明确打开文件优先。修复重开窗口未恢复书籍：非文件激活装配新窗口时恢复旧状态，明确文件激活继续处理新请求。Finder双击/拖放、菜单子项/原生对话框、真实触控板/多屏/NAS与Developer ID公证未验；CI未推送运行。P1 详见[运行记录](../../acceptance/p1-macos-runtime.md)，P2 首批记录单独保存，不继承为完整原版一致性证明。

## 扩展点

P2–P5分别迁原PDF/动图/视频/脚本/播放列表/效果控制逻辑；Windows专属功能逐项登记替换或放弃。Developer ID仅正式分发需要；开发成品的打包/本地签名/重定位与正式分发、公证、安装分开记录。校验后本地提交并推送。

P4第九批整书传输准备可被新打开/窗口关闭取消；授权后原可等待宿主任务和BookOperation.Close等待真实结果及JSON联动。三生产项目/单入口不变，常规验证不激活应用；跨卷/NAS/Windows及集中设备验收另记录，见[契约](../p4-book-transfer.md)。

P5第二十批：原备份/保存/重载命令进入唯一Profile；仅UserSetting原地恢复，来源DirtyBook变化才重收集，前端布局/主题/字体独立恢复。动态预算、旧备份保持、晚到选择器/新打开边界见[契约](../p5-profile-commands.md)。

P5第二十一批：原随机跳页/来源资格排序、地址栏/滑条菜单与快捷键语义、窗口状态与独立设置目录进入唯一命令链。正文与Chrome通知分离；关闭取消/等待系统目录动作。见[契约](../p5-original-commands.md)。

P5第二十四批：原版本窗口布局/图标、实际Mac构建版本、复制/许可/项目链接及macOS关于菜单接入；窗口与阅读独立，Windows更新检查保留Mac待接入区域。见[契约](../p5-version-window.md)。

P5第二十五批：原外部应用命令/集合与独立设置草稿接入；Engine捕获页组及策略，唯一平台字面提交，随机材料进程留存/2GiB共用预算；布局与启动解耦，见[外部应用契约](../p5-external-applications.md)。

P5第三十五批：原单页媒体书、按秒导航、音频/循环和播放条通过唯一BookOperation/JSON/ReaderView接入；AVPlayer提供真实时钟/seek/当前帧，现有工厂计显示帧，原生缓冲共享有界预算。规格变化保留播放器、首帧与晚到结果按原代次裁决，关闭等待真实资源释放。见[视频契约](../p5-video.md)。
