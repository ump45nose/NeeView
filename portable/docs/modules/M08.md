# M08：macOS 生命周期与高级能力

## 职责

唯一正式Host装配、Finder/菜单/拖放打开、窗口关闭与应用退出；高级格式及发布属于后续目标。

## 依赖与契约

MacApp装配Engine/Backends/MacOS表现，只有这里创建具体后端。MacOS/Backends使用net10.0-macos、官方Foundation/AppKit。Program是唯一Exe入口；MainWindow.OpenAsync/RestoreLastAsync/PrepareShutdownAsync可等待。

## 状态与资源生命周期

窗口初始化共用Task，激活等待初始化完成，单窗口。Command+W完成保存后关窗口，应用驻留；Dock重开装配新窗口并恢复最后书籍。Command+Q等共享关闭准备后退出；失败保留窗口并可重试。Finder打开/拖放进入同一个BookOperation加载流程。

## 业务规则

macOS15+、Apple Silicon；完整Xcode必须匹配macOS workload，不新建Preview绕过。保留Info.plist版本/核心格式声明，未完成RAR/7z不向Finder声明支持。发布ARM64自包含.app；脚本只处理正式Host，实际deps/native/许可与基线提交随包记录。

## 错误

默认正式构建目前报找不到有效Xcode开发人员路径，仅安装CommandLineTools。Library源码检查不等于可运行.app。启动损坏JSON保持原文件；系统API失败传播，不以永久删除替代废纸篓。

## 测试与验收

正式源码编译、Headless布局/输入/关闭任务验证；正式.app运行、Finder双击/拖放、Dock重开、Retina/多屏/触控板/NAS及签名公证未执行。CI已更新但未推送运行。

## 扩展点

P2–P5分别迁原PDF/动图/视频/脚本/播放列表/效果控制逻辑；Windows专属功能逐项登记替换或放弃。Developer ID仅正式分发需要，本轮不推送、公证或发布。
