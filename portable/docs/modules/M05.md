# M05：命令、键鼠与触控板

## 职责

保留原命令名、默认输入、参数和语义；菜单/键鼠使用同一命令入口，未迁移命令不以近似动作替代。

## 依赖与契约

Engine.CommandTable 保留 235 条原实例；Mac 宿主处理展示/系统动作。完整默认菜单树来自原 MenuTree.CreateDefault，原语言资源解析中文文案。command-manifest.json 与 command-migration.md 同步标记当前入口及阶段，接入不等于完整参数和输入覆盖。IPlatformInput 输出带窗口身份的 PlatformGesture，由官方 AppKit 实现。

## 状态与资源生命周期

窗口建立后装配 AppKit monitor，关闭释放。只有活动主窗口的查看器区域消费，模态窗口、侧栏和其他窗口继续传播。输入设置为可搜索编辑副本，取消不写入；保存校验后写原 Commands 差分节点，未知参数保留。

## 业务规则

原阅读键位不改；Control 保持 Control，Command 为 Meta。null 缺省用原默认，空串解绑。新增冲突列出命令，旧作用域绑定原样保留，不能阻止无关设置保存；运行时仍报告匹配冲突。旧尚未解析的复杂手势原样保存，但不意味着执行已迁入。HasPreciseScrollingDeltas 区分触控板精确滚动，捏合围绕指针缩放；鼠标普通滚轮走原绑定，不按增量大小猜设备。

## 错误

不可解析新输入和新冲突阻止保存；未迁移动作提示能力。PrevScrollPage/NextScrollPage 接入原 NScroll/PageFrameBox 顺序，不以普通翻页替代；原差分参数读取保留字符串/数字枚举及未知字段。

## 测试与验收

完整菜单占位/勾选、235 元数据、键位 JSON 往返/解绑、原默认鼠标组合可校验、新增冲突/错误值拒绝、文本输入隔离及 Control/Meta 区别。第二批增加五种滚动模式、RTL、终端容差、可注入时钟换行停顿和真实查看器边界翻页测试。合成滚动不作为真实设备识别证据；真实鼠标滚轮、触控板、中文 IME、复杂鼠标组合执行和 Windows 操作对照待验。

## 扩展点

第二批沿用 BookPageMoveControl → PageFrameBox.ScrollToNextFrame → NScroll → ScrollResult 的先滚动/换行停顿/边界翻页顺序，原参数默认值及旧字段映射已迁入。全景 PagesAsOne、完整参数编辑、手势参数、完整输入作用域继续按原控制链迁入。第三批接通胶片条三滚轮模式及作用域选择/确认，JumpPage一起始输入、两方向共享PrevSizePage参数，以及原页面/打开历史四命令。第四批接通PrevBook/NextBook及PrevFolderPage/NextFolderPage；列表/树、排序ComboBox导航键不触发查看器Up/Down。MoveToParentBook继续禁用，浏览父目录不能替代原命令。未知参数仍合并保留，完整滚动参数编辑待后续。

第五批RegisterBookmark保留打开登记编辑界面的含义，FocusBookmarkList需要原书架书签位置/目录树互联，继续禁用占位；未迁入的查询/导航命令继续占位，不能将服务添加动作替代原弹窗命令。

第六批 PrevHistory/NextHistory 按筛选后的访问列表，区别于进程游标；ClearHistory 直接清空、面板更多菜单有确认，FocusHistorySearchBox 明确显示并聚焦。列表 Enter/Delete/单或双击与文本框隔离，原 Panels.OpenWithDoubleClick 默认 false。ClearHistoryInPlace/RemoveUnlinkedHistory 仍禁用，不能用近似文件检测代替原查询与可靠存在能力。

第十六批迁入A/B/C/默认方向/共享参数/按滑条方向运行反转、严格五按钮/单双击/四方向轮滚及普通滚轮配置执行。框架事件/校验留在Mac，原规则留Engine；菜单与输入反转许可区分，表单失败回滚。详细参数、轨迹与真实设备仍继续，见[p2-mouse-input.md](../p2-mouse-input.md)。

第十七批接通整组原变换/BaseScale/Stretch/滚动参数，原拥有者克隆草稿及未知字段合并保留。原参数窗口替换WPF检查器，数值范围不截断未编辑旧值，详见../p2-view-transform.md。

第十八批接通Unload/ToggleBookLock及三方向命令，参数/菜单语义独立；未迁移仍完整占位，详见../p2-book-controls.md。
