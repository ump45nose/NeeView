# M05：阅读会话与命令服务

## 职责

阅读会话与命令服务；以下描述当前实现和后续验收边界，不把设计目标当作已验收结果。

## 依赖

Application → Core。窗口通过 IReaderSession 调用，不依赖具体来源。

## 契约

`IReaderSession` 提供 OpenAsync、NavigateAsync、LocateAsync、SetOptionsAsync、ReportSizeAsync、RefreshAsync、FlushAsync 与 DisposeAsync。
`ReaderSnapshot` 含代次、索引、锚点、显式选择、配置、加载和错误。Changed 是只读通知，订阅方负责 UI 线程。
稳定命令名及 Parameter 分开存储；CommandCatalog.Resolve 只在执行时解释兼容名称。

## 状态与资源生命周期

单读者消息队列串行修改状态；先保存旧书，新来源首批成功后才替换。后台索引回队列提交，检查 generation 和 revision；旧来源/索引退休任务在关闭时收束。

## 业务规则

- OpenAsync 完整索引结束时完成，首批显示不等待后续枚举。
- 目录首批未包含历史 ContentId 时保留待恢复锚点；旧 Page 名在后续批次匹配；用户导航后不再覆盖为旧位置。
- 瀑布流 ActionTarget 只取显式选择；滚动锚点不决定分类目标。
- 导航一秒防抖保存；切书/正常关闭立即保存；保存失败保留队列以便重试。

## 错误

打开失败保留当前来源；空目录是有效空状态。旧解码/索引/文件结果不得修改切换后的画面。

## 测试

CoreTests、ProgressiveTests、UiTests；打开、导航、快速切书、完整/渐进恢复、代次、空状态及分类选择。

## 扩展点

首版单窗口入口；会话已窗口独立，未来多窗口可共享进程服务。
