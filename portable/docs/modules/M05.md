# M05：阅读会话与命令

## 职责

阅读会话与命令，实现范围按整体架构和阶段验收表约束。

## 依赖

Application → Core。

## 契约

IReaderSession；ReaderSnapshot；OpenRequest；CommandService。接口变更同步调用方和本文件。

## 状态与资源生命周期

每窗口独立；串行队列；打开新源成功才替换旧源；一秒防抖。

## 业务规则

NextPage 按 frame；NextOnePage 按资源；锚点和分类选择分离；切书/退出立即保存。

## 错误

失败保留旧书；空目录空状态；旧请求不能替换新书。

## 测试

快速切书、导航、恢复、并发顺序、设置策略。自动测试与真机验收分别记录。

## 扩展点

未来多窗口共享服务。
