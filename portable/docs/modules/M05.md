# M05：命令、键鼠与触控板

## 职责与依赖

保留原命令名、默认输入、参数、配对和执行语义。Engine.CommandTable登记235个原实例；Mac宿主处理展示/系统动作，菜单/键鼠使用唯一命令入口。当前182个入口接通，53个保留原配置与能力占位，数量不表示完整功能覆盖。command-manifest.json、command-migration.md和运行导出同步。

## 契约与生命周期

IPlatformInput输出带窗口身份的PlatformGesture，官方AppKit monitor在启动层装配，窗口关闭移除。只消费活动主窗查看器命中区域，侧栏/菜单/对话框继续传播。ReaderView持有方向序列与指针捕获，失焦/捕获丢失/Escape/切书/关闭取消。设置窗口持有键位、方向及共享参数草稿；取消不写，保存经原ApplyOptionsAsync与SaveData事务回滚。

## 业务规则

Control仍是Control，Command为Meta。空字符串解绑，缺省读取原方案默认；A/B/C先改方案键位再交换配对/滚轮。运行反转受滑条方向、原参数与输入来源约束，菜单保留明确含义。文本、列表、菜单和对话框隔离导航键；胶片条/滑条共享PageSelector，确认后才移动正文。

菜单提示与实际键盘匹配共用 Mac KeyboardGestureParser。原单字符数字转换为 D0–D9，再交给 Avalonia；避免把 `2` 当作 Key 枚举序号而显示 Back。配置原字符串保持不变，鼠标绑定不产生键盘提示。真机 Ctrl+1/2 与菜单 AX 提示、正式菜单 ClickEvent 及别名/特殊键分别验证；CUA 子菜单点击未可靠执行，不计为真实菜单交互通过。

普通滚轮执行原绑定，五按钮/单双击/组合及四方向轮滚保持严格修饰集合。方向U/R/D/L/C独立存储，原距离/夹角生成；右键释放或已有序列左键C终止，命中轮滚取消，原进度提示为命令文本和箭头。默认方向按原阅读方案配对，重复方向字典后登记覆盖；新编辑冲突明确显示，已有配置不阻止无关保存。

PrevScrollPage/NextScrollPage按原NScroll、换行停顿与边界顺序先滚动再分页。完整分页参数、变换/BaseScale/Stretch、页尾/书锁/帧方向、历史/书架/书签/播放列表和焦点命令已接入。原Hover禁用四向/预置/N型滚动但保留分页；无修饰/按钮连续滚轮开启时优先且线性插值。HasPreciseScrollingDeltas可靠区分触控板，不靠幅度猜测；捏合围绕指针缩放。

TogglePageMode/TogglePageModeReverse 分别使用原 +1/-1 和共享 IsLoop（默认 true）；关闭循环时在首/末模式停止，参数草稿独立于控件。参数拥有者映射只共享 JSON，不代表反向命令自动实现。ToggleVisiblePageSlider 与 ToggleHidePageSlider 是不同能力，前者由P5第二十一批接入原显隐语义，不用近似命令替代。

## 错误与验证

新非法输入/冲突拒绝，未知旧字段与尚未迁绑定保留，未迁执行进入能力提示。Headless验证完整菜单占位、键位/方向差分、取消/终止、作用域、组合、原反转、参数/保存失败回滚及图像显示资源。构建与本地签名单独留证；真实鼠标/触控板/IME/Retina、焦点、捕获和Windows动态仍待集中验收。

## 扩展点

原帧全景和Mac连续/瀑布已由P3接入，分类数字命令在P4，高级拖动、触摸屏与高级内容/旧配置完整导入分阶段补齐。现有235个名字、参数和占位继续保持，不以近似动作代替原命令。细节见p2-mouse-input、p2-view-transform、p2-book-controls、p2-direction-gestures与p2-animation契约。

P3第一/二批ToggleIsPanorama和普通ToggleVisibleFoldersTree接通宿主；原帧级全景已由第五批接通；目录树脚本参数仍属于P5。页面列表/目录树方向键只选项，原普通点击/Enter确认与FocusMainView分开，仍进入唯一BookOperation/Bookshelf，见[p3-navigation.md](../p3-navigation.md)。

P3收尾接通ToggleVisibleContentsTree、FocusFolderSearchBox、FocusPageListSearchBox和FocusMainView，前两类搜索显示并聚焦原面板，输入数字/Enter不会路由正文阅读或分类。ToggleVisibleFoldersTree当前Mac宿主显隐已接通；脚本On/Off/ByMenu参数仍明确待P5。完整235实例和禁用菜单保持，数量不换算功能覆盖率。

P4第五批原CopyFile/CopyBook/Paste执行入口接入，CutFile/CutBook按用户决定保留禁用；CopyFile.MultiPagePolicy独立编辑，参数/键位仍从唯一差分JSON读取。菜单展开和窗口重新激活只查询能力，文本输入不转交复制/粘贴阅读命令，见../p4-clipboard.md。

P5 第十七批：原图像动画、播放条/三命令与唯一JSON配置接入，来源/当前帧/显示统一租约预算，取消与原生晚到分别回归。GIF/WebP走Magick，APNG真实ImageIO；详见[动图契约](../p5-animated-images.md)。

P5第十八批：原幻灯播放/首周期等待/页尾覆盖/自动滚动、顶部计时条与独立设置草稿接入；唯一阅读/JSON链保持，关闭失败恢复播放及滚动，见[契约](../p5-slideshow.md)。

P5第二十批：原备份/保存/重载命令进入唯一Profile；仅UserSetting原地恢复，来源DirtyBook变化才重收集，前端布局/主题/字体独立恢复。动态预算、旧备份保持、晚到选择器/新打开边界见[契约](../p5-profile-commands.md)。

P5第二十一批：原随机跳页/来源资格排序、地址栏/滑条菜单与快捷键语义、窗口状态与独立设置目录进入唯一命令链。正文与Chrome通知分离；关闭取消/等待系统目录动作。见[契约](../p5-original-commands.md)。
