P5 第十批：明确打开主题目录使用表单草稿，不提交Config或额外JSON；已有目录/用户样例不覆盖。创建目录属于用户明确按钮动作，取消表单不删除已创建材料；原默认路径与附属导入仍沿唯一Profile，见[目录动作契约](../p5-theme-folder.md)。

P5 第七批将原三个一级附属目录接入预览、独立选择和唯一Profile提交/备份/恢复，列表复用现有格式与Hub；Mac管理目录落点在确认中说明。主题/脚本只保留原材料，不装载或执行。动态恢复清单受限，旧五文件备份兼容。契约见[附属文件导入](../p5-profile-assets.md)。

P5 第六批沿原 Alpha.5 将旧单效果转换为首层/缓存/默认预设，早期Mac保留材料可继续升级，现代层不被旧标记覆盖。原材料归档；预览/应用/普通保存共享唯一JSON链，导入三分支恢复来源缺省。实际效果执行和编辑尚未接入，见[效果兼容](../p5-effect-compatibility.md)。

P5 第五批接入原 DiffJsonConverter 的已迁配置/命令差分写出，保留四模板及九数字实例默认、共享 owner、未知字段和完整关闭布局。旧滚动 setter 与自动隐藏读取别名先转换再退役，原五文件事务与运行 JSON 不变。契约见[差分保存](../p5-difference-settings.md)；旧效果数据由第六批更新；执行仍待迁，附属材料由第七批接入。

P5 第四批接入原独立目录4065/4209升级、旧History字典的单独转换、快速访问内嵌版本校验与缩略目标映射；按最终选项配置归一排序。旧滚动差分setter退役到兼容材料，未知字段保持。范围与生命周期见[目录兼容契约](../p5-folder-compatibility.md)；当时完整原差分写出及旧效果待迁入；差分的当前范围由第五批契约更新。

P5 第三批在五类选择/备份/事务上接入已核对的原旧设置版本规则、参数包装与三代布局。预览先升级再映射，验证/应用共用同一候选；普通配置读取也恢复 V0/V1，未知选择保持关闭。唯一 SaveData 五文件事务继续权威；启动层仍经唯一窗口路径重建引用。字体尺寸、旧效果及完整差分写出仍有明确边界，见[兼容契约](../p5-legacy-compatibility.md)。

## 职责

原 JSON 是唯一权威状态，保留 Config/BookMemento/差分键和未知字段。P2已接入History/Bookmark节点与原集合、登记编辑、常用导航/搜索、列表模板、每目录参数及历史策略；完整旧版本迁移/导入仍在P5。

## 依赖与契约

SaveData.LoadAsync/Find/GetShortcut/SetShortcut/GetMoveSizeParameter/SetCommandParameter/SaveAsync；HistoryEntries 按访问时间倒序，BookmarkRoot 保留 Name/Path/Color/EntryTime/Page/Props/Invalid/Children 与未知字段。ToggleBookmark/AddBookmarkFolder/RenameBookmark/MoveBookmark/SetBookmarkColor/RemoveBookmarks/RestoreBookmarks/ApplyBookmarkEdit 可等待。Page 是条目名。书籍阅读状态优先来自 History，同书所有书签共享；无历史时可恢复书签位置。

## 状态与资源生命周期

独立 ~/Library/Application Support/NeeView.Mac，不写旧 Windows/Portable 数据。UserSetting/History/Bookmark/Foldres/QuicAccess五个临时JSON文件 flush 后准备副本和 .save-pending.json，原子替换；失败恢复旧文件和历史内存，启动恢复中断事务，兼容旧双/三/四文件标记。恢复失败保留唯一副本/标记。书签修改失败原地恢复 Name/Color/Children 及删除恢复记录，节点引用可继续重试；Changed 也用于通知回滚后的导航刷新。全局播放列表沿原.nvpls独立原子保存。

## 业务规则

原默认和枚举不改，Props/未知 token/嵌套字段保留。MacIsSupportedWidePage 补 false 歧义。原 BookMemento 只持久化页面条目名；半页 Part 属于当前阅读，普通切书/启动恢复从该阅读方向的首半页开始。早期 MacPagePart 不再读取，保存当前记录时移除，不清理其他未知字段；同书 LastBookV2 的未知嵌套字段及 Props 保留，切书不带入新书。Find/GetLastBook 返回原 BookMemento，SaveAsync 不接受半页参数。防抖 1 秒、切书/退出立即保存。书签保留层次与顺序，移除仅操作记录。键位编辑不改未知参数。胶片条/滑条已知字段在原分支合并，未知字段保留。跨书导航重放保持原History数组顺序和LastAccessTime，阅读位置继续更新。页面/打开历史各100项环形记录仅在进程内，不另建持久化文件。P5 已迁入版本规则与已迁分支差分写出；未迁设置及真实旧导出仍有明确边界，不能宣称任意旧 Profile 直接兼容。

## 错误

损坏 JSON 保持源文件；写入失败可重试，关闭失败保留阅读窗口。未来值需报告，不能静默删除。多进程共写 Profile 尚未支持。

## 测试与验收

原Path/Page/Props与未知字段往返、书签树顺序/更名/文件夹/删除/合并、历史共享位置、差分键位/方向/共享参数、五文件准备失败回滚、节点身份重试、历史内存回滚、旧双/三/四文件中断恢复、目录/ZIP重新定位、表达式历史/保留/可靠清理及每目录参数均有自动测试。真实两分支导出数据及完整版本迁移未验。
