# M06：配置、历史、书签与旧数据

## 职责

原 JSON 是唯一权威状态，保留 Config/BookMemento/差分键和未知字段。P2已接入History/Bookmark节点与原集合、登记编辑、常用导航/搜索、列表模板、每目录参数及历史策略；完整旧版本迁移/导入仍在P5。

## 依赖与契约

SaveData.LoadAsync/Find/GetShortcut/SetShortcut/GetMoveSizeParameter/SetCommandParameter/SaveAsync；HistoryEntries 按访问时间倒序，BookmarkRoot 保留 Name/Path/Color/EntryTime/Page/Props/Invalid/Children 与未知字段。ToggleBookmark/AddBookmarkFolder/RenameBookmark/MoveBookmark/SetBookmarkColor/RemoveBookmarks/RestoreBookmarks/ApplyBookmarkEdit 可等待。Page 是条目名。书籍阅读状态优先来自 History，同书所有书签共享；无历史时可恢复书签位置。

## 状态与资源生命周期

独立 ~/Library/Application Support/NeeView.Mac，不写旧 Windows/Portable 数据。UserSetting/History/Bookmark/Foldres/QuicAccess五个临时JSON文件 flush 后准备副本和 .save-pending.json，原子替换；失败恢复旧文件和历史内存，启动恢复中断事务，兼容旧双/三/四文件标记。恢复失败保留唯一副本/标记。书签修改失败原地恢复 Name/Color/Children 及删除恢复记录，节点引用可继续重试；Changed 也用于通知回滚后的导航刷新。全局播放列表沿原.nvpls独立原子保存。

## 业务规则

原默认和枚举不改，Props/未知 token/嵌套字段保留。MacIsSupportedWidePage 补 false 歧义。原 BookMemento 只持久化页面条目名；半页 Part 属于当前阅读，普通切书/启动恢复从该阅读方向的首半页开始。早期 MacPagePart 不再读取，保存当前记录时移除，不清理其他未知字段；同书 LastBookV2 的未知嵌套字段及 Props 保留，切书不带入新书。Find/GetLastBook 返回原 BookMemento，SaveAsync 不接受半页参数。防抖 1 秒、切书/退出立即保存。书签保留层次与顺序，移除仅操作记录。键位编辑不改未知参数。胶片条/滑条已知字段在原分支合并，未知字段保留。跨书导航重放保持原History数组顺序和LastAccessTime，阅读位置继续更新。页面/打开历史各100项环形记录仅在进程内，不另建持久化文件。尚未完整迁入原 SaveData 版本升级及差分序列化，不能宣称任意旧 Profile 直接兼容。

## 错误

损坏 JSON 保持源文件；写入失败可重试，关闭失败保留阅读窗口。未来值需报告，不能静默删除。多进程共写 Profile 尚未支持。

## 测试与验收

原Path/Page/Props与未知字段往返、书签树顺序/更名/文件夹/删除/合并、历史共享位置、差分键位/方向/共享参数、五文件准备失败回滚、节点身份重试、历史内存回滚、旧双/三/四文件中断恢复、目录/ZIP重新定位、表达式历史/保留/可靠清理及每目录参数均有自动测试。真实两分支导出数据及完整版本迁移未验。

## 扩展点

原Bookshelf.DefaultFolderOrder/FolderSortOrder及Book.IsPrioritizeBookMove保留；每目录FolderParameter/持久随机种子写入原Foldres.json。内部拖动/顺序移动/递归合并/颜色/批次删除恢复、登记窗口、书签常用导航/查询/排序/四模板均已接入；无效书签修复及高级树布局仍待后续，契约见 ../p2-bookmark-operations.md。P5实施Profile/.nvzip预览、旧版本迁移、最长路径前缀映射，保留Foldres/QuicAccess等原拼写。没有数据库或SQL schema。

原HistoryList的过滤后前后、日期分组与四开关、RemoveHistoryAsync/ClearHistoryAsync共用既有事务；已删除记录在同主图保存时不重新登记，真实主图变化重启登记计数。源文件/书签/搜索历史及未知字段独立；结构化搜索、保留/登记策略、四模板和可靠无效清理已接入。详见 ../p2-history-list.md、../p2-history-policy.md。

P2第十一批接入原书签结构化查询与 History.BookmarkSearchHistory；原 HistoryStringCollection 源码复用，追加/删除在原三文件事务中保存/回滚。System搜索字段与Bookmark递归/搜索框字段合并保留未知配置，默认值沿原版。History.IsKeepSearchHistory 控制已迁书签及第十二批历史表达式落盘，P3收尾已接通书架/页面历史；见[契约](../p2-bookmark-search.md)。

P2第十二批接入History.BookHistorySearchHistory，与书签表达式历史使用同一原HistoryStringCollection和三文件事务，失败恢复同一集合。完整历史字段仍保留，目录/缺失大小-1，原访问时间用作日期谓词；明确Windows逻辑路径保留，但完整Profile路径映射仍在P5。详见[契约](../p2-history-search.md)。

P2第十三批沿原LimitSize/LimitSpan限制文件副本及fromLoad载入，运行集合不受限；数量0不破坏LastBook恢复，其他编辑事务同样遵循已提交限制。设置候选在保存锁中提交，失败不改运行配置。原临时来源过滤在保存数量限制前执行，不排除系统临时目录。原IsSaveHistory/登记阈值/自动无效清理由第二十批接通，见[契约](../p2-history-retention.md)。

P2第十四批将原FolderParameter/FolderConfigCollection接入普通书架，排序按路径保存，随机种子恢复；取代第四批临时全局排序编辑。原Foldres.json加入统一四文件事务；默认归一、父级递归继承、IsKeepFolderStatus写出副本规则及未知/缩略字段保留，见[契约](../p2-folder-parameters.md)。完整Profile路径映射/旧版本导入仍在P5。

第十八批明确Unload使用四JSON事务清除LastBookV2，同时保留历史；失败保留当前来源/原快照供重试，退出Dispose仍为另一生命周期。

第十九批StartUp原LastFolder/LastBookmarkFolder及参数快照沿既有四JSON保存，未知字段与LastBookV2保持，列表位置独立。

第二十批接入原历史登记策略与可靠清理，继续使用唯一BookMementoControl/SaveData及四JSON事务；表现仅编辑草稿与转交命令，见[契约](../p2-history-policy.md)。

P3快速访问及搜索收尾：QuicAccess.json沿原Name/Path/Children保存，树/书架共享节点，失败原地回滚包括新增节点；统一五JSON事务兼容旧恢复标记。原四类搜索历史分别使用HistoryStringCollection，IsKeepSearchHistory控制四类落盘，未知键仍保留。PageList原名称/分组/树/搜索字段、Bookshelf递归/搜索字段和全局增量设置草稿经原ApplyOptions保存，取消不应用。见../p3-quickaccess.md与../p3-page-search.md。
