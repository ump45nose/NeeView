# M06：配置、历史、书签与旧数据

## 职责

原 JSON 是唯一权威状态，保留 Config/BookMemento/差分键和未知字段。P2 首批接入 History 界面和原 BookmarkNode 树字段/基础编辑，第五批接入原集合算法与登记编辑，完整导航/导入仍待迁移。

## 依赖与契约

SaveData.LoadAsync/Find/GetShortcut/SetShortcut/GetMoveSizeParameter/SetCommandParameter/SaveAsync；HistoryEntries 按访问时间倒序，BookmarkRoot 保留 Name/Path/Color/EntryTime/Page/Props/Invalid/Children 与未知字段。ToggleBookmark/AddBookmarkFolder/RenameBookmark/MoveBookmark/SetBookmarkColor/RemoveBookmarks/RestoreBookmarks/ApplyBookmarkEdit 可等待。Page 是条目名。书籍阅读状态优先来自 History，同书所有书签共享；无历史时可恢复书签位置。

## 状态与资源生命周期

独立 ~/Library/Application Support/NeeView.Mac，不写旧 Windows/Portable 数据。三个临时文件 flush 后准备副本和 .save-pending.json，原子替换；失败恢复旧文件和历史内存；启动恢复中断事务，兼容旧双文件标记。恢复失败保留唯一副本/标记。书签修改失败原地恢复 Name/Color/Children 及删除恢复记录，节点引用可继续重试；Changed 也用于通知回滚后的导航刷新。

## 业务规则

原默认和枚举不改，Props/未知 token/嵌套字段保留。MacPagePart 补半页，MacIsSupportedWidePage 补 false 歧义。防抖 1 秒、切书/退出立即保存。书签保留层次与顺序，移除仅操作记录。键位编辑不改未知参数。胶片条/滑条已知字段在原分支合并，未知字段保留。跨书导航重放保持原History数组顺序和LastAccessTime，阅读位置继续更新。页面/打开历史各100项环形记录仅在进程内，不另建持久化文件。尚未完整迁入原 SaveData 版本升级及差分序列化，不能宣称任意旧 Profile 直接兼容。

## 错误

损坏 JSON 保持源文件；写入失败可重试，关闭失败保留阅读窗口。未来值需报告，不能静默删除。多进程共写 Profile 尚未支持。

## 测试与验收

原 Path/Page/Props 与未知字段往返、书签树顺序/更名/文件夹/删除、历史共享位置、差分键位、三文件准备失败回滚、节点身份重试、历史内存回滚、旧双文件中断恢复、目录/ZIP 重新定位。真实两分支导出数据及完整版本迁移未验。

## 扩展点

第四批读取/合并原Bookshelf.DefaultFolderOrder/FolderSortOrder及Book.IsPrioritizeBookMove，未知字段保留。当前仅全局普通书架默认，没有每目录FolderParameter/FolderConfig.json或持久随机种子，不能宣称目录专用排序已兼容。第五批接通内部拖动/顺序移动/递归合并/颜色/批次删除恢复和登记窗口；完整书签导航/查询/列表排序/样式与无效项修复在后续，契约见 ../p2-bookmark-operations.md；P5 Profile/.nvzip 预览、旧版本迁移、最长路径前缀映射，保留 Foldres/QuicAccess 等原拼写。没有数据库或 SQL schema。

第六批接入原 HistoryList 的过滤后前后、日期分组与四开关，RemoveHistoryAsync/ClearHistoryAsync 共用既有事务；当前已删除记录不会因位置保存重新登记，成功新访问才解除进程内抑制。源文件/书签/搜索历史及未知字段独立；完整搜索语法、保留策略/显示模板和无效清理待迁。详见 ../p2-history-list.md。

P2第十一批接入原书签结构化查询与 History.BookmarkSearchHistory；原 HistoryStringCollection 源码复用，追加/删除在原三文件事务中保存/回滚。System搜索字段与Bookmark递归/搜索框字段合并保留未知配置，默认值沿原版。History.IsKeepSearchHistory 控制已迁书签及第十二批历史表达式落盘，未迁书架/页面历史继续保留；见[契约](../p2-bookmark-search.md)。

P2第十二批接入History.BookHistorySearchHistory，与书签表达式历史使用同一原HistoryStringCollection和三文件事务，失败恢复同一集合。完整历史字段仍保留，目录/缺失大小-1，原访问时间用作日期谓词；明确Windows逻辑路径保留，但完整Profile路径映射仍在P5。详见[契约](../p2-history-search.md)。
