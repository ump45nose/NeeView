# M06：布局与主查看器

## 职责

布局与主查看器，实现范围按整体架构和阶段验收表约束。

## 依赖

Core 计算；Desktop 绘制。

## 契约

ILayoutStrategy；LayoutSnapshot；LayoutItem；Paged/Continuous/Masonry。接口变更同步调用方和本文件。

## 状态与资源生命周期

只保存几何；按列高度索引可见查询；显示资源按可见需求租约。

## 业务规则

最短列，平局按阅读方向；320 DIP/8 DIP；锚点补偿；设备像素 1:1。

## 错误

未知尺寸占位，探测晚到重排保持锚点。

## 测试

万条目、长图、尺寸晚到、窗口变更、模式切换、Retina。自动测试与真机验收分别记录。

## 扩展点

检查点增量重算与 GPU 渲染。
