# M10：macOS 生命周期与发布

## 职责

macOS 生命周期与发布，实现范围按整体架构和阶段验收表约束。

## 依赖

MacOS Host/Platform.MacOS → Desktop/Application。

## 契约

OpenRequest 队列；IPlatformService；AppKit NSWorkspace/NSFileManager。接口变更同步调用方和本文件。

## 状态与资源生命周期

启动事件排队；W 关闭窗口保留应用；Q 保存并退出；无窗口重开。

## 业务规则

Finder/拖入/菜单统一；Application Support/Caches；自包含 ARM64；实际依赖许可。

## 错误

退出先等待文件操作；Xcode/签名不足明确未验收。

## 测试

双击、菜单、废纸篓、重开、签名公证和安装。自动测试与真机验收分别记录。

## 扩展点

Intel、其他桌面 Host。
