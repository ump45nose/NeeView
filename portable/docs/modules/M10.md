# M10：macOS 生命周期与发布

## 职责

macOS 生命周期与发布；以下描述当前实现和后续验收边界，不把设计目标当作已验收结果。

## 依赖

Host 装配 Desktop 和具体实现。MacOS/Platform.MacOS 使用 net10.0-macos；Preview 使用 net10.0。

## 契约

DesktopApp 统一初始路径、激活事件和无窗口重开；主窗口 OpenAsync/RestoreLastAsync 可等待。
IPlatformService RevealAsync/TrashAsync；正式实现使用 NSWorkspace/NSFileManager。package_macos.py 顺序 publish、装配、依赖许可、签名、公证。

## 状态与资源生命周期

Command+W 保存并释放窗口会话，应用继续驻留；重开恢复 LastSource。Command+Q 等文件服务、保存、查看器和共享容器释放后退出。应用数据/缓存独立放 Application Support/Caches。

## 业务规则

- Finder、拖放、菜单进入同一 OpenRequest；首版单窗口。
- ARM64 自包含 Preview .app/zip 用于开发，无外部 SDK 运行依赖；正式 Host 需要完整 Xcode。
- 依赖从实际 .deps.json 生成；NuGet NOTICE/LICENSE、仓库 MIT、原生文件清单随包保存。
- 清单保留 commit、基线、dirty；native unsigned_sha256 明确为签名前哈希。
- 可选 Developer ID/notarytool 凭据由用户环境提供，脚本不创建、换号或改全局配置。

## 错误

本机只有 CommandLineTools，正式 Host 报“找不到有效的 Xcode 开发人员路径”；有效签名身份 0。Preview ad-hoc 不是正式签名、公证或干净安装证明。

## 测试

Preview 构建、56 项测试、七来源真实解码/恢复冒烟及开发包 ad-hoc codesign verify 已通过。2026-10-02 解锁后的 Command+W 关闭/激活重开、Command+Q 进程退出、完整重启位置/模式恢复及 Finder 定位通过，见 [本机记录](../../acceptance/macos-ui-2026-10-02.md)。Finder 打开/拖放、真实触控板/多屏、正式 AppKit 废纸篓和正式安装仍待验。CI 已配置但未推送、未运行远端。

## 扩展点

Intel/其他桌面增加 Host/Platform 适配，共享 UI 和业务不引入条件化系统依赖。
