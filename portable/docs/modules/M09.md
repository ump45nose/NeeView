# M09：快速分类与文件操作

## 职责

快速分类与文件操作；以下描述当前实现和后续验收边界，不把设计目标当作已验收结果。

## 依赖

Application 串行协调；IDestinationFolderService 提供目录数据，IPlatformService 执行系统能力。

## 契约

`IFileActionService.ExecuteAsync/UndoAsync/RedoAsync` 返回真实成功、路径和内容身份。`RecoverAsync` 消费日志并报告无法验证记录；`DrainAsync` 正常退出等待操作。
`RecoveryOperation` 保存阶段、SHA256、临时/覆盖备份和撤销附加恢复路径。

## 状态与资源生命周期

进程级互斥和撤销/重做栈，容量默认 300、范围 0–1000，退出清空。
日志状态机：preparing → ready → target-committed → source-deleted → identity-relocated → finalized。ready 后不盲目回滚，保留记录续做；有待恢复记录时禁止叠加写入。

## 业务规则

- 上区手动目录不限数量，前九数字；下区直接子目录不写配置。自动只在目录改变时枚举，手动刷新可强制。
- 仅目录真实图片可写；分页默认主图片，瀑布流显式选择。MoveToFolderAs 固定移动；数字/面板跟随复制开关，Copy 固定复制。
- 复制不入移动历史；成功移动推进下一项，末项退前，空目录进入空状态。
- 覆盖先明确选择并备份；移动经临时目标、SHA256 验证和刷盘后提交，完成后再删源。
- 撤销/重做包含被覆盖文件恢复；外部修改摘要不符拒绝删除或覆盖；失败/取消不弹栈。
- 身份重定位幂等，联动历史/书签/目标目录阅读状态，刷新来源和缓存版本。

## 错误

归档只读、权限、同名、过期版本及外部内容变化均报告；不能确认的中断保留文件和日志，不自动猜测。

## 扩展点

批量操作需独立事务与显式多选；可增加覆盖备份保留期限/清理 UI，不能回收仍被日志依赖的备份。
