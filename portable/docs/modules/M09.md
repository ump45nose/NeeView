# M09：分类与文件操作

## 职责

分类与文件操作，实现范围按整体架构和阶段验收表约束。

## 依赖

Application 协调；平台执行。

## 契约

IFileActionService；IDestinationFolderService；FileActionResult 实际路径。接口变更同步调用方和本文件。

## 状态与资源生命周期

进程共享互斥和历史；数据库记录中断恢复；容量 300/0..1000。

## 业务规则

手动目录无限前九数字；直接子目录不持久化；复制不入栈；固定 MoveToFolderAs；跨卷验证再删；覆盖备份。

## 错误

失败/取消保留栈顶；归档只读；覆盖必须选择。

## 测试

移动复制、映射、undo/redo、覆盖、权限、跨卷、NAS。自动测试与真机验收分别记录。

## 扩展点

批量操作和恢复 UI。
