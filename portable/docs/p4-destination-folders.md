# P4 第一批：原 fork 分类链路

本批迁入原两区面板、目标管理、九数字命令、固定移动菜单、单图移动/复制和进程共享撤销/重做。仍只有 Engine/Backends/MacOS 三个生产项目，JSON 是唯一配置及阅读状态权威；不增加数据库、另一个阅读内核或诊断宿主。

## 原源码与适配

- DestinationFolder/Collection 保留 Name/Path、名称回退、Trim、克隆和无限集合。Shell 方法从数据类型移到后端。
- DestinationMoveService 保留非排队忙碌锁、双栈、仅成功变栈、失败/取消保留栈顶和容量裁剪；启动层注入一个实例，窗口重开继续共享。
- 原 DestinationFolderPanelViewModel 的手动上区/当前目录下区、目录变化刷新与取消控制迁入 Engine.DestinationFolderPanel；Mac 同名表现模型只管理通知。
- 原分类 XAML 区域与两区独立列表转换为 DestinationFolderPanelView.axaml，继续使用原侧栏停靠/组合/浮动宿主。
- 九命令的数字默认绑定及可配置 Index 由原构造器补齐；差分只写 MultiPagePolicy 时不丢失数字索引。Index=0 在宿主打开菜单。MoveToFolderAs 始终移动，数字/面板跟随复制模式。

## 契约和生命周期

BookOperation.AttachFileOperations 注入进程服务、文件后端及唯一 BitmapFactory。普通目录中的真实图片参与分类；归档、符号链接、书籍项及未完成索引不可分类。保留原 System.IsFileWriteAccessEnabled=false 默认值，面板可显式启用原开关。瀑布需要明确点击；滚动锚点、悬停、临时页选择不改变分类对象。

BookOperation 原导航锁协调文件结果与索引修改。请求捕获 Book/Page，锁内再核对；操作完成前新书不能提交，切书不把旧分类对象解释为新页面。移动后在原 SourcePages 移除对象，再按原排序重建可读集合，优先下一图、末图退前、无图清空当前页。复制保留源图和正文位置；递归书内落点按真实结果替换/追加Page，其他Page引用保持，覆盖目标不复用旧像素。Undo 在当前恢复目录重载定位，跨目录只提示，不自动切书；同书Undo/Redo重载保留临时搜索；Redo 移出当前目录后同样更新原集合。所有封面失效复用原工厂。

配置沿用 System.DestinationFolderCollection 与原五个 Panels 字段；DestinationFodlerCollection 仅读取兼容，保存归入正确拼写。上区不限数量，前九数字命令默认对应前九目标；下区不写入上区配置。目录不变的翻页不枚举；手动刷新和新建直接子目录沿已有来源/后端能力执行。配置保存失败深拷贝恢复已提交字段和集合，真实文件成功后的阅读保存失败经既有防抖/切书/退出重试。

窗口退出禁止新动作、关闭采集对话框、等待已授权文件动作，再保存并释放来源。移动历史退出不持久化；覆盖备份和操作记录留在应用独立 FileRecovery 目录供崩溃恢复/会话撤销。

## 文件操作和恢复

FileOperationBackend 单槽后台执行：写恢复记录 → 临时目标复制/SHA256 → 目标及源同目录原子暂存/再次验证 → 覆盖副本 → 无覆盖安装目标及必要的覆盖还原 → 完成记录 → 清理暂存。普通卷和跨卷使用同一协议，不把 File.Move 的跨卷隐式复制当完整性证明。

同名必须明确覆盖或取消；取消不变栈。Undo 的反向记录同时恢复被覆盖目标，Redo 再次保留它；撤销位置自身冲突也保留副本。成功后才更新历史栈。容量0–1000，默认300；淘汰只清理本应用生成的备份/记录，用户文件不在清理范围。

Undo/Redo带原内容和副本指纹，外部替换不弹栈。安装是提交点，晚取消仍完成必要日志及原书协调。启动仅按指纹自动回滚能确认的未完成动作，已完成记录清理；外部更改/损坏/断线导致无法确定时保留材料并提示检查，不覆盖新文件。当前记录在 Application Support，目标临时文件使用随机 .neeview 名称。未开始写入或已取消不会报告成功。

## 本批边界

- 本批只迁入原 Once 单主图策略；原 All/AllLeftToRight 字段保留、执行明确提示未迁入，不能静默把批量解释成单图。
- 原 fork 移动不修改整本书的历史/书签地址。分类是书内单图移出，不能将原目录书籍地址改成目标目录；本批保存当前书的新位置，原独立书签/播放列表路径不推测迁移。重命名与明确文件定位联动在下一批实现。
- 原 DeleteFile/剪贴板 CopyFile/CutFile/RenameBook 仍占位，不能把分类复制视为这些命令已迁移。
- 长文件系统调用仍可能延迟完成；有界后台和导航互斥保持界面响应，未验证 NAS/权限/真实跨卷中断。当前每次完整性校验成本是明确的可靠性选择，同卷原子移动优化需测量后独立迁入。

## 验收

静默测试使用临时图片副本/Profile，覆盖主图/下一图/末图/空目录、模式/数字改绑、归档只读、覆盖/取消、连续UndoRedo的两端恢复、容量/新分支、指纹中断恢复/外部变化保留、父级别名及瀑布显式选择，正式XAML数字输入与文本作用域。

用户指定图片目录仍只读，不进行真实分类。P3剩余真机、无损Retina、完整焦点/弹出层、Windows动态及长期性能，与P4设备/分类流程统一安排。触控板按用户要求跳过，多屏无环境。常规验证不启动/激活正式应用，不发系统键鼠。构建、自动测试、真机/Windows、用户验收、提交和发布分开报告。

此协议减少检查后覆盖/删除的目录项竞争，不宣称跨进程文件写入互斥或任意NAS原子性；持有旧句柄的外部并发写入及真实断线由集中验收继续确认。恢复仅清理应用命名且路径/内容可验证的材料，不能确定时保留。
