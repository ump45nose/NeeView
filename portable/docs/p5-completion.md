# P5 收尾：打印、原输入/窗口和设置入口

## 职责、依赖与原出处

本批继续沿唯一 Engine / Backends / MacOS 生产链迁移，不增加阅读内核、状态数据库或系统模拟层。原 PrintModel/PrintController、PageViewRecorder、MouseInputNormal/AutoScroll、WindowStateManager 和 Script item 出处及基线指纹记入 source-migration.json。

Engine 保存原参数、纯打印几何、TSV停留记录、脚本实体操作和JSON路径联动；Backends使用官方AppKit执行打印并报告真实后端；MacOS负责打印表单、同一查看器快照、指针时钟、窗口状态及设置动作。视图不读取归档、枚举目录或执行实体改名。

## 契约与业务规则

- Print保留四模式、方向、背景、像素保持、水平/垂直对齐、毫米边距及1–4行/列。行列表示同一画面铺到多张纸，不是多图缩略槽。打印区域采用系统实际纸张及不可打印边距，附加负边距按原规则合并后取非负。
- PrintCurrentAsync复用原输出忙碌、导航互斥和关闭等待。选项/预览/系统面板占同一任务；准备阶段支持取消。已提交原生打印等待系统真实结果，取消返回false。所有当前帧媒体在输出期间暂停，仅恢复仍由同一查看器持有的播放器。
- 原图模式取首图像源；View使用同一页框/变换/效果导出。独立背景覆盖整铺纸区域。预览只表示内容，最终纸张分页由系统打印面板确认；连续/瀑布需先回分页或原帧全景。
- PageViewRecorder默认关闭，沿原字段追加TSV、时长格式及切书/切页/切换文件边界。状态拍照在短锁内，后台单写入者和512项队列持有文件；不隐式创建父目录。高频超限明确回报丢行；关闭最终行异步等待容量，不丢终止快照。重复/并发关闭等待同一完成任务。诊断订阅者抛异常不打断阅读。
- 鼠标长按保留Loupe/AutoScroll/Repeat、按钮掩码、1秒默认等待和0.1秒重复。拖动、方向序列、释放、捕获丢失、失焦或关闭取消。自动滚动保留原速度公式、死区、16上限及毫秒位移；长按进入时释放最后一键停止，普通模式按原停止交互配置处理。切书/宿主重挂无条件停止，同书尺寸更新保持。
- FullDesktop复用实际查看器宿主，保存普通位置/装饰；负坐标屏幕采用并集，尺寸按桌面比例换算。退出恢复Normal/Maximized；启动读取原LastState，主窗和中央浮窗一致。混合缩放多屏仍需真机验证。
- Bookshelf脚本Name改实体，复用写权限、来源释放、JSON marker、索引和历史恢复链；Open(bool)仅覆盖本次递归，不改默认。Bookmark Name只改节点；folder LastWriteTime是原EntryTime，文件项按需读真实元数据，CreationTime和Size保持原语义。JS Date以UTC毫秒提供时间。
- LoadRecentBook呈现原可选择最近菜单及数量，不能直接打开第一项。SelectArchiver展示当前真实读取后端；当前单后端无切换候选。FocusPrevApp/NextApp轮巡自身主窗/中央及侧栏浮窗，不能切换其他应用。
- 设置的图像效果/导入入口可明确选择“保存后打开”或“放弃修改后打开”，成功关闭后才转交现有效果面板/Profile导入。保存失败留在原表单，不执行后续动作。17类设置入口沿同一草稿与结构化搜索。

## 状态和资源生命周期

来源、阅读器及BitmapFactory不增加实例。打印快照为请求独立PNG；NSView/NSImage及请求NSPrintInfo在主线程释放；末次成功纸张设置只保留一个进程级副本，系统操作串行。后台原生测试使用真实NSPrintOperation保存PDF，使用AppKit导出的NSString键值，不能将符号名误当字符串值；不创建或激活产品窗口。

记录器退订、补行、队列完成及文件关闭按顺序进行。实体改名后晚取消不撤销已成功操作；JSON失败保留恢复marker，不用未证实的路径匹配清除。窗口适配器随宿主关闭退订，指针计时器随查看器释放退订。关闭先取消各显示需求并归还显示租约，再等待同一BitmapFactory已退休的像素与动画资源归零；无消费者的原生晚到结果仍由加载finally清理。系统动作只在用户命令调用时允许焦点变化；自动验证保持静默。

## 错误与兼容边界

打印机/纸张/硬件输出及系统面板交互未由无面板PDF测试替代。TouchEmulate是WPF触摸调试模拟，Mac保留禁用能力说明；CutFile/CutBook按用户选择继续禁用。Windows专用插件/ClearType/libVLC实现不引入Mac。

原未知JSON和未对应的Windows配置仍保留。本批不宣称分卷归档、内部目录提取原TODO、系统更新器或全部Windows平台专属能力已迁入。真实两分支导出、固定Windows动态一致性、混合缩放多屏、AX长期资源和NAS不可及时取消仍按既有记录计；用户跳过的浮窗菜单/停靠及屏幕P95不重开。
