## 46.3 fork 的版本声明

真实 fork `ddc857b511e9f04cbc356bdabb1f748963e4f9e1` 把产品及 Profile 格式版本改成 1.0.0。对共同基线到该提交的 SaveData / Config 对照，仅分类面板配置增加字段，原格式升级代码没有改变。不能将它按原历史 1.0 升级，也不能自动把所有 1.0 当成现代格式。

`ProfileImportSource.Schema` 默认 `DeclaredVersion`。用户在导入预览中明确确认源码来源后，才选择 `ConfirmedNeeView46_3Fork`。只对准确的 1.0.0、匹配的文件类型与现代根结构采用已核验的 46.3.4340 schema；未知枚举、错误根类型、未来版本继续拒绝应用。

只读来源在预览中复制。候选先规范化成原现代版本，再进入既有 Upgrade / Request / SaveData 事务；原 Format 放在 `MacImportedSourceFormat`，schema 放在 `MacImportedSourceSchema`。这些保留字段不能自行启用确认。没有第二套解析或存储模型。

旧 Bookmark 内嵌 QuickAccess 仍是独立文件缺失时的后备。确认外层不放行未知内嵌 Format；确认的现代内嵌结构在预览中分别规范化。独立文件继续优先，实际选择在创建请求及应用时再次验证。修改确认或更换来源立即使旧预览失效。

## 效果编辑的控件生命周期

原六分支、效果层及设置事务不变。下拉展开时只维护候选，关闭后提交，避免每次方向导航都清空 popup 宿主。事务成功或失败回滚后，表单按分支 / 层位置 / 字段归还焦点；前一层参数数量变化不改变后一层编辑位置。控件身份只存在于视图，不进入效果 JSON 或业务模型。

主窗口仍使用原键位与既有 popup / 编辑作用域隔离。新增 Headless 用例从真实 MainWindow 按键路由进入，核对书籍与页位、提交、保存失败回滚及跨层表单变化。原生 popup 焦点和 Windows 灰度显示的通过状态单独记录。

## NAS 边界

传输、取消及恢复仍使用同 exe 无窗口 worker、原随机日志、源 / 暂存 / 目标哈希。没有提高 15 秒无进展限制，也没有改变系统挂载或用户共享。

独立代理仅用于本轮隔离断线。部分写入阶段人为限速 2 MiB/s，恢复与成功重试采用正常速率。限速下的 Flush / Close 超过无进展限制曾触发取消并回滚，保留为真实边界；正常速率成功不能外推任意低速连接都能完成。后台父进程有界返回与正式窗口 Command+Q 是两项验收。

本轮结果见[最终收尾记录](../acceptance/p5-final-closure.md)。Developer ID / 公证按用户决定延期；AX 与已确认的加密 RAR 分卷限制继续保留，不重新纳入目标。
