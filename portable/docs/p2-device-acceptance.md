# P2 真机与 Windows 动态验收

本轮范围为真实触控板、Retina、Windows 原版动态对照和长期进程资源。多屏缺少环境，单独保留待验。遵循[静默验证约定](validation-workflow.md)：后台准备不启动正式应用，真实输入和远程桌面操作集中安排，不将工具连接成功计为功能通过。

## 共用数据与后台工具

```sh
python3 portable/scripts/generate_device_fixtures.py /tmp/neeview-device-fixtures
python3 portable/scripts/sample_macos_process.py --pid <正式应用PID> --output /tmp/neeview-device-memory.csv --interval 5 --duration 1800
```

输出目录/CSV 必须尚不存在。生成器提供 9 张有页号和左右色条的分页图、3 张 800×600 像素棋盘格、12 张 3840×2160 图、阅读/内存 CBZ、PNG SHA256 清单及空 WindowsProfile。生成数据只用于规则、像素映射和内存压力，不替代照片、复杂格式或屏幕性能样本。两端先核对 SHA256，再使用相同文件及显式设置。

采样器只读取指定 PID 的 RSS、CPU 和数字文件描述符，进程退出停止，CSV 逐行刷新。它不启动应用、触发翻页或强制 GC；RSS 不等于缓存用量，也不能区分托管堆与原生分配。长期测试须结合实际浏览、缓存/临时文件情况和必要的原生分配检查，不能只运行采样器后宣布无泄漏。

## Windows 入口与基线

1. TCP 3389 可达只证明远程桌面入口；登录、桌面会话、参考程序版本及操作结果分别核对。SSH 是后台辅助入口，不是动态对照的先决条件。
2. 原版可执行文件的 ProductVersion/FileVersion、SHA256 和安装目录 NeeView.settings.json 的 PackageType/Revision 必须留证。固定源码基线为 46.3 fork / c5c398d89；安装版 Revision 若是占位或版本不同，不宣称已经匹配固定基线。
3. 原版环境变量 NEEVIEW_PROFILE 指向已存在的绝对目录，只对验收启动进程设置，不能修改系统环境。先核对已有 NeeView 进程及单实例转发行为；不能让隔离启动把样本转交给用户现有实例。必要时使用独立程序副本或安排用户正常关闭现有实例，不能强制终止。
4. SSH 登录中的盘符映射不一定等同于用户桌面；安装目录必须在实际验收会话重新确认。远程桌面可能锁定本机桌面，也可能改变显示分辨率和 DPI；记录实际值，远程截图不能作为物理屏幕性能证据。
5. Mac 当前没有 NEEVIEW_PROFILE 隔离入口。正式运行前正常关闭应用、备份默认 Application Support 数据，结束后还原并校验；不能假设设置该变量即可隔离 Mac 数据。未安排前台时段时不执行备份后的替换、应用启动或真实输入。

OpenSSH 可选组件安装若失败，保留错误和系统版本再选择恢复方式；不为此自动更改 Windows Update 策略、代理或防火墙。复制命令使用完整单行或脚本文件，避免续行符被粘贴空行打断。误建规则先按其具体名称禁用，再确认协议、端口及来源地址，不能以规则存在作为安装成功的证据。

## 动态用例

| 项目 | 操作与证据 | 通过标准 |
|---|---|---|
| 阅读规则 | 两端使用编号目录及 CBZ；记录单双页、左右方向、封面/末页单页、宽图/分割开关；每次记录页号/半页、设置和截图 | 相同操作后的主图、页框顺序、半页和步进一致；NextPage 与 NextOnePage 分别对照 |
| 排序与恢复 | 切换排序、切书、正常退出再打开；保存实际显示内容、原 Path/Page/Props | 原定位及设置恢复一致；不以数组序号近似原半页位置 |
| 历史与书签 | 用测试 Profile 建文件夹/记录，进入、返回、排序、搜索、导航；正常重开 | 顺序、选择、导航对象及保存行为符合原业务；未迁命令保留占位并记录能力差异 |
| 菜单与左右侧栏 | 检查菜单占位；跨栏拖动、组合、拆组、比例调整、自动隐藏、浮动、停靠及重开；录图并记录区域/选择 | 组合关系、焦点/捕获、视口和布局恢复符合原目标；不能只检查静态布局 |
| 触控板 | 用户在 Mac 查看器执行精确滚动/惯性、捏合、边界；再在覆盖侧栏、文本框及菜单执行；单独核对普通鼠标滚轮 | 精确事件不重复触发普通轮滚命令；缩放中心及滚动方向正确；覆盖面板和文本输入不误操作正文；需要实际硬件事件 |
| Retina 100% | 记录屏幕模式及实际 RenderScaling；在 100% 显示 800×600 棋盘格，保存原生分辨率截图并测量图像边界/格子；与适合窗口区分 | 图像占 800×600 设备像素；不能仅以看起来清楚判定；缩放、旋转和视口裁剪条件明确 |
| 长期资源 | 真实进程每 5 秒采样，持续 30–60 分钟重复浏览 4K 目录/CBZ、切书、浮动/停靠和关闭/重开；记录各操作区间及两段同负载复测 | 预热后相同负载的 RSS/句柄/临时文件不持续线性增长；缓存预算和租约回收分别核对；原生趋势异常再用 Instruments 等定位 |

触控板由用户实际操作，远程桌面鼠标事件不能替代。多屏本轮标记未验。NAS、复杂图像/归档和 Finder 等已有待验项继续独立保留；本表的通过不自动覆盖它们。
