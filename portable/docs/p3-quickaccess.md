# P3 第六批：快速访问与普通目录树补齐

当前状态：P3开发范围已完成，见[P3收尾清单](p3-completion-checklist.md)；本文件记录该批契约和当时测量，后续接入点以下述链接为准，静默验证不等同真机/Windows封板。

沿原 QuickAccessCollection/QuickAccessTreeNode/QuickAccessDirectoryNode 迁入 Name、Path、Children、逻辑文件夹、别名、树重排及原 `QuicAccess.json` 文件名。唯一 SaveData 事务现提交五个 JSON 文件，旧四/三/二文件恢复标记继续兼容。编辑失败原地恢复旧节点、父子关系和顺序，包括移除尚未提交的新增节点；不建立第二身份或状态体系。

普通树拥有 Mac 根与挂载卷根，QuickAccess 是同树的独立根。快速访问树与书架列表投影同一节点；名称变化保持位置与选择，当前位置删除退回根。点击普通目录只浏览书架，快速访问目标通过既有加载入口打开，逻辑文件夹只浏览列表。内部拖动仅在快速访问中重排/移入，普通目录拖到快速访问登记目标；外部文件拖放同样只登记引用。真实文件复制、移动、重命名、废纸篓保留 P4 禁用占位。

目录监视通过既有来源接口实现，只监视已加载且展开的一级目录，最多32项，250ms合并变更。折叠、祖先隐藏和关闭立即释放；旧监视回报按ID拒绝。重新显示/展开时补刷新停监视期间的变化；不支持监视的来源仍复用原懒加载缓存。树选择随删除退回有效父节点，失败保留旧子树和错误信息。

系统图标通过 IPlatformService 返回小型 PNG，AppKit对象只在后端主线程创建/释放，并发2、缓存最多64项。Desktop只在实际可见时转换 Bitmap；离屏/隐藏/脱离取消释放，晚到结果拒绝。同次显示失败保留备用图标，重新进入后重试，不在布局事件中反复请求。

前端 FolderTreeView 只处理焦点、上下文及拖动反馈；MainWindow 的独立适配负责异步对话框与调用；Engine维护唯一节点/保存/来源监视。样式不改变上述规则。退出等待已授权的快速访问编辑，关闭后的对话框回报不提交。

QuickAccessTests 覆盖原JSON未知字段/顺序、编辑及新增失败回滚、树/书架节点共享、名称和循环保护、正式TreeView拖动和合成截图；DirectoryWatchingTests 使用临时真实目录检查创建/重命名/删除、隐藏补刷新与释放。完整测试、正式Library/.app及签名另留证。系统图标API仅编译验证，未标记真实Finder图标/焦点/拖放/Retina通过。旧Profile导入和高级属性修复在P5。
