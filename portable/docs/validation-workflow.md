# 验证流程：默认静默，前台交互单独安排

2026-10-03用户要求验收不要突然激活NeeView影响其他工作。本约定用于后续各批迁移，不改变产品的窗口、焦点或输入语义。

## 默认后台执行

- 源码/依赖边界、构建、签名、xUnit、正式XAML Headless渲染及资源/持久化测试在后台完成；继续串行使用默认bin/obj。
- 自动回归装载正式视图/后端源码，不增加Preview入口或第二套阅读内核。
- 已生成截图、AX证据、日志及JSON可直接离线审查；不为查看结果反复启动或激活应用。
- 未约定前台时段时，不自动启动正式应用，不发真实键鼠、拖放、菜单或全屏动作；在大节点报告列出剩余真机验收。

## 前台交互单独验收

原生焦点、激活/失活、弹出菜单、真实拖动捕获、触控板/IME、全屏及Finder等必须按实际Mac行为验收。提前约定可占用电脑的短时段，按清单集中执行，完成后还原验收数据；不在用户工作过程中逐次抢焦点。

当前cua的Mac接口未提供明确的 `activate:false` / 静默键鼠选项。取得目标应用绑定或后台AX/截图成功不代表之后的输入没有激活窗口，也不代表并发切换应用不会影响焦点。界面交互仍使用cua；不通过其他输入脚本绕过这一边界。

若用户在交互验收期间切换应用，保留已观察的显示/落盘结果，记录并发条件。相关焦点、悬停、捕获和弹出层项目标记需复验，不由连续获取状态或工具调用成功判定通过。后台构建及Headless结果继续单独报告。

## 交付状态

构建、自动测试、Headless视觉、正式Mac运行、原版对照及用户验收分别记录。静默回归不替代真实设备验收；前台待验不影响独立可运行增量的本地提交，但不能因此封板。需要完全无干扰的持续真机交互时，另行讨论独立测试设备或桌面环境，本项目不默认引入额外基础设施。

## 后续实图资源约定

2026-10-04用户指定 `/Volumes/Picture/YY/秀人/5001-6000` 作为之后看图、瀑布流及缩略验证资源。每次挑几个直接包含图片的子目录及少量滚动/定位用例，不要求全量或递归跑所有内容；不得因采样目录不含某格式而声称该格式实图验证通过，格式/坏图仍使用可复现合成夹具。用户目录保持只读、状态使用临时Profile；实图截图仅留本机忽略的artifacts，Git报告只保存匿名数值/哈希。Headless使用正式XAML和真实后端，默认保持后台，无前台焦点操作。
