# P2 第十六批：原输入方案与鼠标组合

## 职责、依赖与契约

Engine沿原CommandConfig、CommandTable.CreateDefaultMemento/SetShare和CommandTools.ResolveCommand迁入A/B/C、六对默认键位、滑条方向交换及共享参数。没有第二命令或状态体系；235个原定义继续保留。Mac的MouseGestureSource统一处理设置校验和事件匹配，Avalonia类型不进入Engine。

## 业务与生命周期

- 先方案覆写，再按PresetPageReadOrder交换配对键位及WheelUp/Down。原已配置ShortCutKey优先，空字符串解绑；缺省才读取方案默认。恢复默认键位按钮只改草稿，参数保留，保存为原Commands差分。
- 原Ctrl与Mac Meta分别匹配，修饰顺序/同义词归一，键盘及Pressed按钮集合严格相等。支持五按钮、单双击、WheelClick中键别名及四轮滚方向；新冲突明确提示，未迁命令仍报能力。
- 扩展组合与双击在按下裁决，优先于拖动及普通释放。Avalonia在已有按钮按下时的额外变化从PointerMoved.PointerUpdateKind接入；静默正式事件路由验证，不作为原生设备结论。组合消费后抑制所有本次按下的普通释放，捕获丢失取消待确认动作。
- 轮滚按作用域/轴/修饰积累有符号余量，反向抵消。多格逐次执行，水平默认最多一步；右键滚轮消费后不追加右键翻页。普通Ctrl/Meta滚轮不强制缩放/平移；精确触控板仍由原生HasPreciseScrollingDeltas桥接。
- 按键/点击按滑条与方案方向比较，仅原配对且IsReverse允许时交换。菜单按明确语义执行；垂直与水平轮滚各自读取许可。共享参数向原拥有者写入，早期Mac独立参数只作读取兼容。
- 原ViewScroll四向先指定轴、到边界后按阅读方向尝试跨轴，不翻页；Scroll参数默认0.25、AllowCrossScroll=true。

## 状态与错误

设置保存通过BookOperation原导航锁，取消旧防抖，保存失败原地恢复Config已知分支、书籍设置及Commands节点，保留原对象引用及未知字段。成功后只在阅读字段变更时重建正文；外观/输入编辑不请求解码。仍采用四JSON原子提交，无数据库。

查看器上下文菜单复用原完整菜单树/占位和统一执行回调，关闭后解除临时宿主，避免方案切换后自动弹旧菜单。文本、列表、菜单、页号、滑条及胶片条作用域继续保留。

## 测试与验收

MouseInputTests覆盖六种默认方案/方向、同义组合/严格修饰、冲突、差分/未知字段/重启、运行反转许可、共享参数、多格/半格/反向/修饰轮滚、右键轮滚释放抑制、组合/单双击/X按钮/拖动、C方案纯滚动、文本隔离和表单失败回滚/重试。正式输入设置图独立保存。

全量及正式构建/本地签名见本批验收JSON。真实鼠标扩展按钮、双击时序、触控板、IME、弹出菜单与Windows动态对照待集中前台验收，Headless不替代这些结论。

## 扩展点

完整缩放/旋转/翻转与滚动参数编辑、鼠标轨迹、窗口浮动及其余P2控制继续按原源码迁入；此批不是完整输入与P2封板。
